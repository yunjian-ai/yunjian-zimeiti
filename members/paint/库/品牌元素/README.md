# 品牌元素模板（首批）

> 需求单第 6 问「品牌元素」用：主人要加、又没有现成的，按元素挑 2～3 个方案给主人看。主人有自己的 logo、字体、宣传语，一律用主人的。
> 品牌元素**全部做成图层**，不让模型画进底图（这样主人能拖着调，字也不会被画错）。平台对字有要求的只提醒、附出处，照主人的设计做。

| 元素 | 卡 |
|---|---|
| logo | brand-logo-jiaoluo 角落小 logo｜brand-logo-dibu 底部品牌条 |
| 宣传语条 | brand-slogan-hengtiao 底部横条｜brand-slogan-shupai 左侧竖排｜brand-slogan-dingbu 顶部标题区 |
| 角标 | brand-jiaobiao-xie 左上斜角标｜brand-jiaobiao-yuan 圆形徽章｜brand-jiaobiao-jiaonang 胶囊标签 |
| 价格条 | brand-jiage-ditiao 底部价格条｜brand-jiage-yuanbiao 右下价格圆标 |
| 字体 | brand-font-siyuan-hei 思源黑体｜brand-font-siyuan-song 思源宋体｜brand-font-puhui 阿里巴巴普惠体 |

**字（宣传语、价格、角标上的词）**：照主人给的原话，一个字不改；主人没给就问，或建议找写稿的执笔。成分、数字、「包邮」「正品」这类说法要主人确认属实才放。
