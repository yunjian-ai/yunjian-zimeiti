# 平台规格（只认官方）

> 给 AI：出图前先查这张表。尺寸、比例、文件大小照做（不照做传不上去）；内容类要求（能不能放字、放什么）只提醒主人、附出处，主人定，不擅改主人的设计。标「待核」的平台先停下，不出成品。
> 机读版在同一文件夹的 `规格表.json`（自检脚本读它），两份一起改。
> 出处只有两种：平台官方文档原文，或商家／创作者后台上传时的提示和裁剪框。核对日期写在每节标题后面；平台改了规则，以后台当下的提示为准，并更新这张表。

## 一、电商

### 抖店（2026-10 核：抖店工作台学习中心官方助手＋官方文章）
| 图 | 官方要求 |
|---|---|
| 1:1 主图 | 至少 3 张，建议 5 张；必须 1:1；至少 600×600；png/jpg/jpeg；≤5M；**第一张必须是商品主体完整正面实物图**（不能用局部、纯文字、虚拟图）；不许完全相同、同角度重复、无关水印 |
| 3:4 主图 | 不低于 375×500，推荐 750×1000；≤3M；jpg/jpeg/png；无牛皮癣、无文字、无水印、无拼接、无变形拉伸；从店铺、橱窗、商城「猜你喜欢」进商详通常展示 3:4 |
| 主图上的字 | 可以放品牌 logo；所有主图不得含有除品牌 logo 以外的任何文字、水印（卖点字、促销语属「牛皮癣」风险）——**只提醒** |
| 白底图 | 背景白色；建议 800×800；72dpi；png/jpg；<3M |
| 详情图 | 单张宽 620～1290，高不超过 2000；≤5MB；jpg/jpeg/png；超尺寸自动裁剪 |
| 直播封面 | 官方未给统一尺寸；重点是图片清晰、光线明亮、实景拍摄、主体适中、主题明确 |

### 微信小店（2026-10 核：官方接口文档「添加商品」＋商家后台填写助手）
| 图 | 官方要求 |
|---|---|
| 1:1 主图 | 不少于 3 张、最多 9 张，不得重复；**前三张按顺序：商品正面实物图、包装标签图、其他细节图**；建议 600×600～1440×1440；png/jpg/jpeg；单张不超过 10M（部分类目 1M） |
| 3:4 主图 | 最多 1 张，比例 3:4 |
| 白底图 | 最多 1 张，1:1，照主图尺寸；背景纯白 |
| 详情图 | 1～50 张，必须有图；像素、大小没有硬性规定；不放联系方式、网址、第三方信息 |
| 易错点（后台原文） | 打码、PS 遮挡、手机截图、其他电商平台信息；图和标题对不上；裁剪不完整、出现边框、**文字信息被截断**、空白图 |

### 电商通用
- AI 生成的图按《人工智能生成合成内容标识办法》（2025-09-01 施行）和平台要求标注。
- **与实物一致**：颜色、外形、logo、包装字、配件数不改，不画没有的效果，不做假买家秀。

## 二、自媒体

### 小红书（2026-10 核：创作服务平台发布页、创作百科）
| 图 | 官方要求 |
|---|---|
| 图文图片 | 不限宽高比，**推荐 3:4 至 2:1、不低于 720×960**；单张最大 32MB；推荐 png/jpg/jpeg/webp，不支持 gif、live 图；最多 18 张；整篇的显示区域以第一张为准，上传相同尺寸效果更好 |
| 图文封面 | 第一张就是封面，发现页双列卡片按第一张显示 |
| 视频封面 | 默认第一帧，可另设；裁剪可选 3:4（默认）、4:3、1:1；优质封面：画质清晰、比例在 3:4 至 4:3 之间、包含视频主旨信息、**文字不遮挡重要内容**、构图和谐色彩舒适；反例：比例不合适出现黑边、信息密度低、展示不全 |
| 长文封面、直播封面 | 待核 |

### 抖音（2026-10 核：抖音创作者中心发布页；官方《视频上传说明》）
| 图 | 官方要求 |
|---|---|
| 图文 | 推荐 jpg/jpeg/png/webp，不支持 gif；单张不超过 50MB；不建议宽高比超过 1:2，**推荐 3:4、4:3**；最多 35 张 |
| 视频封面 | **竖封面 3:4＋横封面 4:3，建议两个都设**；优质封面：**分辨率 1200×900（横）或 900×1200（竖）**、包含视频主题关键词、构图合理色彩适宜；封面字：提炼关键词，**不遮挡主体，占比小于 30%** |
| 文章封面 | 必填，裁剪框 3:4 |
| 文章头图 | 选填，裁剪框 3:4；标题、摘要压在图的下半截（约从高度 58% 到 84%），主体放在上面一半多一点 |
| 视频画幅（参考） | 推荐 16:9、9:16、3:4、4:3；9:16 左右边缘留安全距离 |
| 直播封面 | 官方未给统一尺寸（同抖店） |

### 公众号（2026-10 核：微信官方文档「新增草稿」「上传永久素材」）
| 图 | 官方要求 |
|---|---|
| 文章封面 | 裁剪比例只有 **2.35:1 和 1:1** 两种（同一张图裁两次） |
| 贴图（图片消息） | 最多 20 张，第一张是封面；封面裁剪 1:1、16:9、2.35:1 |
| 图片大小 | 图片素材 10M 以内，bmp/png/jpeg/jpg/gif；接口上传的正文图片 jpg/png、1MB 以下 |
| 封面、正文配图像素 | 官方没写 |

### 视频号
**待核**：封面、图文、直播封面都还没核对官方。做视频号的图先停下，跟主人说清楚。

### 海报（朋友圈、社群）
没有平台规格，问主人发在哪、要多大。
