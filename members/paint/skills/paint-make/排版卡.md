# 排版卡：字多、版式要准的图（paint-make 用；判法见 paint-brief 的 `判档卡.md` 第五节）

> 卡类：口径｜改了要回归考题

海报、长图、价目表、招募图、活动规则图——字多、价格多、以后还要改。最怕字错一个、价格写两个、颜色对不上。做法：**模型只画画面（不带字）→ 字从锁死清单取、排上去 → 逐条对**。

## 一、先有锁死清单
需求单里没有「锁死清单」不排（`需求单卡.md` 第七节）。文案是丹青替主人写的，先在聊天里给他过目，点头了再锁；锁了以后改字只改清单，不在版式里手打。

## 二、两档（丹青自己选，不问主人）
| 档 | 条件 | 交什么 |
|---|---|---|
| 基础版（默认） | 什么都不用装 | PNG＋JPG（字是叠上去的，要改字用 paint-adjust 拖着调） |
| 升级版 | 这台电脑已经有 PhotoCraft（`photocraft-cli`） | PSD（字是真文字层，Photoshop 里能改）＋PNG＋JPG |
`排版.py` 自己看有没有 PhotoCraft：有就出升级版，没有就出基础版，不卡住、不替主人装。

## 三、要不要装 PhotoCraft（只问一次）
主人说「要 PSD」「要分层」「给设计师接着改」、这台电脑又没有 PhotoCraft 时，问一句：
> 这类图装个免费开源的 PhotoCraft，能交可以在 Photoshop 里改字的分层文件。要装吗？不装我照样交 PNG 和 JPG。

- 同意：`python3 后期.py 装`（下载官方发布包、核 sha256），装好再排。
- 不同意：照基础版交；把「不装 PhotoCraft」记进视觉档案，以后不再问。
- 主人没提要分层：不问，直接交基础版。

## 四、版式怎么写（`版式.json`）
和 `图类写法卡.md` 最后一节的图层表一样，只有一处不同：**字层不写 `text`，写 `"锁": "<文案 id>"`**。
```json
[
  {"id": "顶条", "type": "rect", "color": "#3B2A1E", "x": 0, "y": 0, "w": 1, "h": 0.16},
  {"type": "text", "锁": "标题", "x": 0.06, "y": 0.04, "w": 0.88, "h": 0.08, "color": "#FFFFFF"},
  {"type": "text", "锁": "价格", "x": 0.06, "y": 0.64, "w": 0.88, "h": 0.08, "color": "#FFFFFF"}
]
```
- **网格**：左右边距一样（常用 6%～8%），字块左右对齐到同一条线；离四边至少 4%。
- **字号层级**：标题最大，价格第二，说明最小；同一级的框高度一样，字号才一样。
- **留白**：段和段之间至少空出一个说明字的高度；一屏别塞超过 6 段。
- **颜色**：字和色块只用锁死的色值；深底配白字、浅底配主色。
- 每段锁死文案都要排上，一段都不能漏；不在清单里的字不加（「限时」「爆款」也不行）。

## 五、怎么排、怎么交
1. 底图：模型出不带字的画面，用 `交付.py` 裁到锁死的尺寸；纯色底就不给底图，脚本照底色铺。
2. 排：`python3 排版.py 需求单.json 版式.json -o <作品文件夹> [--底图 底.png]`
3. 看最后一行：`OK 升级版｜…` 或 `OK 基础版｜…` 才算过；`没过` 照上面的 ❌ 改版式或清单再排。
4. 自检已经跑过；单独再查：`python3 ../paint-check/check_paint.py <作品文件夹> --lock 需求单.json`。
5. 交付：照常走 paint-check；升级版附 PSD，说一句「字是可以改的文字层」。基础版说一句「要改字在调图网页里改」。

## 六、自检查什么（`排版回执.json` 逐条对锁死清单）
| 查 | 不过的样子 |
|---|---|
| 每段文案一字不差 | 改了一个字、多了空格、少了标点 |
| 一段不漏、不多 | 框太小字放不下被跳过、多了没锁的字 |
| 只有一个价 | 多出一个「原价 ¥99」 |
| 颜色 | 字或色块用了清单外的颜色 |
| 尺寸 | PNG／JPG 不是锁死的像素 |
| 禁写 | 禁写的词出现在图上 |
升级版的字是从 PSD 里读回来对的，基础版对的是排进去的字层（叠图放不下会跳过，跳过的算漏）。
