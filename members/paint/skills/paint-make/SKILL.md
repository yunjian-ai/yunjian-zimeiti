# 按需出图

先读进度文件（`~/.yunjian/paint/进度.md`，没有就照岗位说明里的四块建）：上回做到哪，有断点就接着做，不从头再问。

**单图**（paint-brief 判的，记录里 `档: 单图`）：照同目录 `单图卡.md` 做，不立母版、不走下面的套餐和母版对照；下面各步是**系列图**的。

## 0. 先读
- 需求单（`我的库/需求单/` 最近一张，或 paint-brief 刚交的）：**单子上有几张出几张**，套餐只在 `套餐: true` 时用。
- `~/.yunjian/paint/库/平台规格.md`：这家平台这种图的硬规矩和交付像素。标「待核」的平台停下，不出成品。
- 要用的母版：`我的库/母版/`（身份证「不许改」一节、单张）；没有就先交 paint-master。
- 同目录的 `图类写法卡.md`（每种图怎么出、字留哪、出多大）、`套餐卡.md`、`后期卡.md`（字、价格、角标、颜色版本、批量、PSD 交给 PhotoCraft）；景、品牌元素、参考照需求单选的卡。
- 主人说「照上次那套」：读 `我的库/成品/<套名>/配方.md`，只换内容，其余照配方。

## 1. 排这一单
列一张小表：第几张｜图类｜平台｜交付像素｜用哪几个母版｜景｜图层。跟主人说一句「这单出 N 张，最多调 X 次出图」，X 照需求单报的上限（已立母版花掉的也算进去）；张数和上限都和需求单一致就不用等回话。

**系列图**照 paint-brief 的 `系列流程卡.md` 走，每条回复第一行带进度条，每发一条带进度条的回复前跑一次 `python3 ../paint-library/库管.py 进度 <单名> --现在 … --出图 … --下一步 …`（系列流程卡第五节），不手写：
- 母版要主人确认过（状态「主人确认」「丹青自查」「入库」）才开始出；还是「草稿」就停下，先交 paint-master 给主人确认。
- **3 张以上**：先出 1 张定调样张——挑最难的那张（人＋货＋景都有的），走完下面第 2～4 步发给主人，进度条停在「③ 定调样张 ⏸ 等您看」；主人说对了再出其余几张，说哪里不对只改那一处。主人说过「直接出」就不停。
- 出其余几张时，每出 3～4 张更新一次进度条（好了几张、还剩几张、用了几次出图），不闷头做到最后。

## 2. 出底图
- 照图类写法卡写提示词：主角放 Image 1，身份证「不许改」原文贴上，写清给字留哪块空，写死「No text, no logo」。
- 人物挑参考：身份证有「造型」的，穿这身出镜就喂 `单张/造型-正面.png`（看背面加 `造型-背面.png`），造型那几条也原文贴上；要某个表情就加喂 `单张/表情-<那个>.png`，提示词写「facial expression exactly as in Image N」；没有造型、表情板的照旧喂打底板单张。
- `python3 ../paint-master/出图.py 图生图 "<提示词>" -r 单张/板-1.png [-r …] -o 作品/<日期>-<单名>/大图-1.png -s <引擎尺寸> -q medium`。
- 退出码 3（没设密钥）：用 Bot 自带的出图，提示词照用，出完照样走后面几步。出来的图比交付像素小（比如最大只有 1280×720、要交 1920×1080）：照样放大交付，把「Bot 自带出图最大多少」记进视觉档案，当场告诉主人近看会偏软、要原生像素就设 GPT Image 密钥。
- 细节图不生成，从原图裁（paint-master 的 `细节.py`）。

## 3. 裁压、叠图层
一张图三个文件分开放：引擎出的 `大图-1`、裁压后的干净 `底-1`（调图网页用它）、叠好图层的 `成品-1`。**别把成品写回底**——网页再叠一层就会出现两个 logo。
1. 裁到交付像素：`python3 交付.py 大图-1.png --size <交付像素> --max-mb <上限> --out 底-1.jpg`（白底图加 `--white`）。
2. 写 `图层-1.json`（图类写法卡最后一节；描边、投影、渐变字、竖排、弧形字、圆框、爆炸贴、优惠券见 `后期卡.md` 第四节）：位置照选的品牌元素卡，字照主人原话。
3. 叠（后期）：这单第一次用先跑 `python3 后期.py 装`；再 `python3 后期.py 排版 底-1.jpg 图层-1.json -o 成品-1.png [--psd 成品-1.psd]`，最后一行 `OK` 才算过（`没过` 写着哪层字不对，改了重排）。系列图交付附 PSD；同一版式换图换价出多张用 `后期.py 批量`，抠好的商品出几个颜色用 `后期.py 换色`（后期卡第二节）。叠完跑一次 `交付.py --check 成品-1.png --size … --max-mb …`（超了用 `交付.py` 压成 jpg）。
   - `后期.py` 退出码 3（装不上 PhotoCraft）：改用 `python3 叠图.py 底-1.jpg 图层-1.json -o 成品-1.jpg`（只认横排字、贴图、色块，新加的效果会被跳过，交付时说一句）；`叠图.py` 也退出码 3（没有 Pillow 或中文字体）：成品先交底图，图层交给 paint-adjust 做成调图网页，主人在网页里导出。
   - 调暖一点、抹掉领标、白底图换底色、放大：先用 `后期.py 调色／去瑕疵／抠白底／放大`，不花出图次数；后期卡第三节那几样（有背景的抠图、扩图、抹大东西）还是交给模型改图。
4. **商品身上的印花、图案、字、logo 不让模型画**：底图里那块模型画的不算数，照后期卡第二节「印花贴回」从原图抠出叠上去，几个颜色共用同一块。
5. 公众号封面：出一张 2.35:1，再从正中裁一张 1:1（`交付.py --size 1080x1080`），两张都检查主体和标题完整。

## 4. 自检、交付
- 每张交 paint-check 查（规格、对母版、字、合规）；不过重出那一张，最多 2 次，每次都算进这单的出图上限；上限用完先停下问主人，还不过说清卡在哪。
- 做法和说好的不一样（比如说好重出、实际改用调色或贴回）：交付第一句先说换了什么、为什么、效果差在哪，不悄悄换。
- 交付照 paint-adjust 的交法：图直接发进聊天，第一句讲清「这是按某平台某规格出的成品」；附调图网页，说一句「哪里不满意，下载这个网页用浏览器打开，自己拖；聊天里的预览拖不动」；末尾说一句这单实际调了几次出图。平台对字有要求的，在图下提醒一句、附出处，不擅改主人的设计。
- AI 生成的图，交付时提醒主人发布时按平台要求标注（`平台规格.md` 电商通用）。

## 5. 记住
- 每单存 `我的库/作品/<日期>-<单名>/`：大图、底、图层、成品、用了哪些母版和提示词原文。演练模式下只打印，不写。
- 主人说「存成模板」「以后都照这个」，或同一套被选中 3 次：存成品配方 `我的库/成品/<套名>/配方.md`（用了哪几个母版、景、品牌元素、每张的图类和顺序、提示词原文、交付像素、哪些是每次要换的内容）＋成品样张。用过的库卡 `用过` 加一（交 paint-library 计数）。

## 防误伤
- 主人要一张就出一张；没在单子上的图不出，「顺手多出几张」也不行。
- 商品的颜色、印花、纽扣数和母版对不上，不交；印花不一样不算「小偏差」，换成原图贴回；颜色、纽扣改提示词重出，不靠解释糊过去。
- 主人给的字（标题、价格、宣传语）一字不改；字放不下先问能不能缩短，不自己删字。

## 写进度
干完写进度文件：做到哪、下一步、等主人定什么；主人纠正过的记一行（演练模式下只打印）。

## 不做
定需求（paint-brief）、立母版（paint-master）、拖着调网页（paint-adjust）、写标题文案（找云间的执笔）、替主人上传发布。
