# 按需出图

**单图**（paint-brief 判的，记录里 `档: 单图`）：照同目录 `单图卡.md` 做，不立母版、不走下面的套餐和母版对照；下面各步是**系列图**的。

## 0. 先读
- 需求单（`我的库/需求单/` 最近一张，或 paint-brief 刚交的）：**单子上有几张出几张**，套餐只在 `套餐: true` 时用。
- `~/.yunjian/paint/库/平台规格.md`：这家平台这种图的硬规矩和交付像素。标「待核」的平台停下，不出成品。
- 要用的母版：`我的库/母版/`（身份证「不许改」一节、单张）；没有就先交 paint-master。
- 同目录的 `图类写法卡.md`（每种图怎么出、字留哪、出多大）、`套餐卡.md`；景、品牌元素、参考照需求单选的卡。
- 主人说「照上次那套」：读 `我的库/成品/<套名>/配方.md`，只换内容，其余照配方。

## 1. 排这一单
列一张小表：第几张｜图类｜平台｜交付像素｜用哪几个母版｜景｜图层。跟主人说一句「这单出 N 张，最多调 X 次出图」，X 照需求单报的上限（已立母版花掉的也算进去）；张数和上限都和需求单一致就不用等回话。

单子超过 5 张或要先立母版：母版好了先报一句，之后每出 3～4 张报一次（好了几张、还剩几张、用了几次出图），不闷头做到最后。

## 2. 出底图
- 照图类写法卡写提示词：主角放 Image 1，身份证「不许改」原文贴上，写清给字留哪块空，写死「No text, no logo」。
- `python3 ../paint-master/出图.py 图生图 "<提示词>" -r 单张/板-1.png [-r …] -o 作品/<日期>-<单名>/大图-1.png -s <引擎尺寸> -q medium`。
- 退出码 3（没设密钥）：用 Bot 自带的出图，提示词照用，出完照样走后面几步。出来的图比交付像素小（比如最大只有 1280×720、要交 1920×1080）：照样放大交付，把「Bot 自带出图最大多少」记进视觉档案，当场告诉主人近看会偏软、要原生像素就设 GPT Image 密钥。
- 细节图不生成，从原图裁（paint-master 的 `细节.py`）。

## 3. 裁压、叠图层
一张图三个文件分开放：引擎出的 `大图-1`、裁压后的干净 `底-1`（调图网页用它）、叠好图层的 `成品-1`。**别把成品写回底**——网页再叠一层就会出现两个 logo。
1. 裁到交付像素：`python3 交付.py 大图-1.png --size <交付像素> --max-mb <上限> --out 底-1.jpg`（白底图加 `--white`）。
2. 写 `图层-1.json`（图类写法卡最后一节）：位置照选的品牌元素卡，字照主人原话。
3. 叠：`python3 叠图.py 底-1.jpg 图层-1.json -o 成品-1.jpg`，再跑一次 `交付.py --check 成品-1.jpg --size … --max-mb …` 确认叠完还在大小上限内。退出码 3（没有 Pillow 或中文字体）：成品先交底图，图层交给 paint-adjust 做成调图网页，主人在网页里导出。
4. 公众号封面：出一张 2.35:1，再从正中裁一张 1:1（`交付.py --size 1080x1080`），两张都检查主体和标题完整。

## 4. 自检、交付
- 每张交 paint-check 查（规格、对母版、字、合规）；不过重出那一张，最多 2 次，每次都算进这单的出图上限；上限用完先停下问主人，还不过说清卡在哪。
- 交付照 paint-adjust 的交法：图直接发进聊天，第一句讲清「这是按某平台某规格出的成品」；附调图网页，说一句「哪里不满意，下载这个网页用浏览器打开，自己拖；聊天里的预览拖不动」；末尾说一句这单实际调了几次出图。平台对字有要求的，在图下提醒一句、附出处，不擅改主人的设计。
- AI 生成的图，交付时提醒主人发布时按平台要求标注（`平台规格.md` 电商通用）。

## 5. 记住
- 每单存 `我的库/作品/<日期>-<单名>/`：大图、底、图层、成品、用了哪些母版和提示词原文。演练模式下只打印，不写。
- 主人说「存成模板」「以后都照这个」，或同一套被选中 3 次：存成品配方 `我的库/成品/<套名>/配方.md`（用了哪几个母版、景、品牌元素、每张的图类和顺序、提示词原文、交付像素、哪些是每次要换的内容）＋成品样张。用过的库卡 `用过` 加一（交 paint-library 计数）。

## 防误伤
- 主人要一张就出一张；没在单子上的图不出，「顺手多出几张」也不行。
- 商品的颜色、印花、纽扣数和母版对不上，不交；改提示词重出，不靠解释糊过去。
- 主人给的字（标题、价格、宣传语）一字不改；字放不下先问能不能缩短，不自己删字。

## 不做
定需求（paint-brief）、立母版（paint-master）、拖着调网页（paint-adjust）、写标题文案（找云间的执笔）、替主人上传发布。
