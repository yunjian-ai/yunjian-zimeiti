# 后期卡（paint-make 用：底图出好以后，精确的活交给 PhotoCraft）

> 卡类：事实｜核对 2026-10-27｜下次核对 2027-01-25（照官方重核一遍，改了日期跟着改）

> 人话：模型画画面，**字、价格、角标、尺寸、颜色版本、批量、可改的 PSD** 这些要一字不差、一像素不差的活，交给 PhotoCraft（开源、免费、像 Photoshop 的软件，丹青用命令替主人操作它）。几样以前要让模型重出一张的小活（调暖一点、抹掉领标、白底图换底色、放大）也交给它，省出图次数。脚本是同目录 `后期.py`，只用标准库。
> 下面「交给」「不交给」两张表都是云间用真商品图逐项实测过的（2026-10-26）；Grok Bot 也实测过能自己装、自己排完一整单。

## 一、先装（每台电脑、每个 Bot 盒子第一次用）
`python3 后期.py 装`：找本机的 PhotoCraft 命令行，没有就从官方发布页下（Mac 约 72 MB、Linux 约 85 MB，对过官方校验值才用），装到 `~/.yunjian/paint/工具/`；没有中文字体顺手装上 Noto Sans SC。
- 打印 `OK PhotoCraft…` 才往下；打印 `NO_TOOL`（退出码 3，没网、平台不支持）→ 这一单改用 `叠图.py`，不卡主人、不让主人去装。
- 不替主人装到「应用程序」里，也不改系统设置；只放在丹青自己的文件夹。

## 二、交给它的（实测合格）
| 活 | 命令 | 注意 |
|---|---|---|
| 字、logo、价格、角标、圆框、优惠券叠到底图上，出成品＋PSD | `后期.py 排版 底.jpg 图层.json -o 成品.png --psd 成品.psd` | 图层写法见第四节；脚本自己读回每个文字层对字，`没过` 就是字被改了，查出来再交 |
| 同一个版式换图、换名、换价出 N 张（多 SKU、上新、价目） | `后期.py 批量 底.jpg 图层.json 数据.csv -o 目录 [--psd]` | 数据第一列「文件名」，其余列名＝图层 id；值以 .png/.jpg 结尾就换那层的图 |
| 抠好的商品换几个颜色（燕麦、雾蓝…） | `后期.py 换色 商品透明.png -o 目录 --色 燕麦=32,28,-12 --留深色 130` | **只给已经抠好的透明底商品换**；`--留深色` 让扣子、深色印花不变色（胡桃木扣 130、黑扣 70）；换完逐张看扣子、印花对不对 |
| **印花贴回**（商品身上的印花、图案、字、logo）| 从商品原图抠出**只含印花的透明图**（白底上的印花用 `抠白底`；和衣服同色抠不干净的，交出图模型「只去掉衣服底色、印花一笔不改」再抠，抠完和原图并排核一遍）；图层.json 里作为 image 层叠到前片对应位置，浅色衣服加 `"blend": "正片叠底"`，深色衣服不加（保留印花原色） | **印花一律不交给模型画**；几个颜色共用同一块印花；换色时先给衣服换色、再叠印花 |
| 调暖一点、亮一点、更通透 | `后期.py 调色 图.jpg -o 出.jpg --暖 25 --亮 0.3 --鲜 20` | 商品颜色要跟实物一致，调完对一眼母版颜色 |
| 抹掉领标、线头、小污点 | `后期.py 去瑕疵 图.png --框 x,y,w,h -o 出.png` | 只用于小东西（框小于图的 5%）；放大看有淡痕要告诉主人 |
| 白底商品图抠透明、换底色 | `后期.py 抠白底 图.png -o 透明.png [--底色 #D9C7B0]` | 只用于**纯白底**的图 |
| 放大 2 倍 | `后期.py 放大 图.png -o 出.png --倍 2` | 比普通放大清楚，不是 AI 补细节 |
| 多尺寸（淘宝 800、小红书 1080×1440、公众号 900×383） | 继续用 `交付.py` 裁压；要每个尺寸排版不一样，就每个尺寸各写一份图层.json | 坐标是比例，同一份图层.json 换尺寸也能用 |

## 三、不交给它的（实测不合格，交给出图模型或说明做不到）
自动调色（会把米白调成冷灰蓝）、有背景的照片抠主体、给整张图选主体换色（墙和靠垫一起被染）、扩图、抹掉大东西（内容识别填充会糊）、背景虚化（衣服也虚了）、3:4 硬改 1:1（商品被拉胖）、动图和视频（只能出单张）。
→ 要「认出东西、补出新画面」的，都交给出图模型改图（paint-master 写法卡第六节），PhotoCraft 只管精确的那一半。

## 四、图层.json 新增的写法（老写法照旧，`叠图.py`、调图网页都还认）
坐标、大小仍是占整张图的比例（0～1）。在原来 `text`／`image`／`rect` 上加：
| 字段 | 用在 | 意思 |
|---|---|---|
| `"gradient": ["#E0282F", "#7A0A12"]`、`"angle": 0` | text、rect | 渐变字、渐变色块 |
| `"outline": {"color": "#FFFFFF", "width": 5}` | text、image | 描边（字的白边、细节圆的白边） |
| `"shadow": {"opacity": 35, "distance": 6, "size": 12}` | 都能用 | 投影 |
| `"glow": {"color": "#FF5A4E", "size": 18}` | 都能用 | 外发光 |
| `"vertical": true` | text | 竖排 |
| `"curve": 30` | text | 弧形字（-100～100，正数往上拱） |
| `"spacing": 200` | text | 字距（千分之一个字宽） |
| `"strike": true` | text | 划线（原价） |
| `"weight": "black"` | text | 字重：regular／medium／bold／black |
| `"shape": "circle"`／`"round"` | image | 图片放进圆形／圆角框（细节放大圆、头像） |
| `"type": "ellipse"`、`"burst"`、`"star"` | 新形状 | 圆形徽章、爆炸贴、星形 |
| `"radius": 0.18`、`"notch": true`、`"stroke": {"color": "#C8102E", "width": 3, "dash": true}`、`"fill": false` | rect | 圆角（≤1 按短边比例）、优惠券两侧半圆缺口、虚线边、只要边不要填色 |
| `"rotate": -12`、`"opacity": 0.9` | 都能用 | 斜放、透明度 |
| `"blend": "正片叠底"`（也认「滤色」「叠加」「柔光」或英文 Multiply） | image、rect | 混合方式；印花贴回浅色衣服用正片叠底，吃到褶皱和光影（`叠图.py` 不认，会照正常贴） |

## 五、几个不报错的坑（都实测踩过，照做）
1. **换色只用剪贴在商品上的调整层**：脚本已经这么做；不要自己在别处插层，插错位置会染整张图而且不报错。
2. **一层一层验收**：脚本最后一行 `OK` 才算过；`没过` 后面写着哪层字不对。**多颜色、批量出完，逐张看商品**（扣子、印花、logo）。
3. **字放不下就缩字号**：脚本会缩到框里放得下，提示「框太小」时先问主人能不能缩短，不自己删字。
4. **离边缘不到 4%** 会提醒：照图类写法卡挪进来再出。
5. **PSD**：系列图交付时附一份（主人或设计师用 Photoshop、PhotoCraft 打开能直接改字）；单图主人要才给。PSD 几 MB，一并发或说放哪。
