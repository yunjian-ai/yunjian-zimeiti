# 图片卡（出图、改图）

> 先过 `规则卡.md`，这里只写出图的骨架、看对象的差别、改图和一致性。

## 骨架（按这个顺序写） [官方·Google]
1. **画幅和类型**：16:9 / 1:1 / 3:4；产品图、海报、写实摄影、插画、3D……
2. **主体**：是谁、是什么，写具体（「一只深灰色紫砂壶，壶身有细砂颗粒」，不写「一个茶壶」）
3. **动作或状态**：在干什么、处于什么状态
4. **场景**：在哪；分近、中、远几层写更有空间感
5. **构图和机位**：近景 / 远景、俯拍 / 平视 / 仰拍、焦段（85mm 显亲近、35mm 像纪实、长焦压缩空间）
6. **光和色**：光从哪来、软硬、冷暖；主色调 2～3 个（「柔和窗光，暖白和原木色」）
7. **风格和质感**：材质、颗粒、年代感；可以说参考哪类风格，不要只写「高级感」「电影感」这种空词
8. **避免**：不想出现的（文字乱码、多余的手、杂乱背景）——Midjourney 除外，见下

**写成连贯的句子**，不要一串关键词：出图模型懂语言，描述画面的句子比堆词效果好。[官方·Google]

## 看对象写
| 工具 | 要点 | 来源 |
|---|---|---|
| Midjourney | **英文、正文不超过 40 个词**（官方说法是 40 个词以后开始被忽略；写完数一遍，参数 `--ar`、`--no` 不算）；只写想要的，不写「no xx」句子（写了反而容易出现），要排除用参数 `--no xx`；用具体的视觉词（rim light、shot on 35mm），不用 nice、cool | 官方·Midjourney |
| Gemini、GPT 出图这类对话式出图 | 中文也行；写成一段完整描述；图里要出现的文字用引号原样写出来 | 官方·Google；常见做法 |
| 国内工具（即梦、可灵等） | 默认按中文写、按上面骨架；主人说出来的图对不上，再附一版英文 | 常见做法 |

主人没说用什么工具：按对话式出图的写法写，用法里补一句「要用 Midjourney 告诉我，我改成英文短版」。

## 改图 [官方·Google]
- 直接说改哪一处、改成什么，**同时说哪些保持不变**（「只把背景换成浅木纹桌面，壶和光线都不变」）。
- **一次只改一处**，确认对了再改下一处；一次塞五个要求，容易全改乱。

## 一致性（同一个人物、产品要出好几张）
- 先做「定妆照」：人物或产品的正面、侧面、背面几张参考图，后面每次都带上。
- 每张提示词都把人物外观、服装、产品细节重复写一遍，不写「同上」。

## 交付样子

