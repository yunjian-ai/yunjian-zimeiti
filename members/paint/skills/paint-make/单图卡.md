# 单图卡（paint-brief 判成单图后用）

> 单图：这一单的图不用锁同一个人、同一件货（判档卡）。**不立母版、不走七问、不等回话**——想法梳理清楚、提示词写准，模型本身就能出好。一张图 1 次出图，重画留 1 次。

## 1. 梳理想法（三四行，聊天里说）
把主人的话理成：**主体**（是谁、是什么，写具体）、**画面**（在哪、在干什么、构图）、**风格**（光、色、质感）、**规格**（平台和像素，照 `~/.yunjian/paint/库/平台规格.md`；没说平台的按用途挑常用比例，并说出来）、**字**（图上要出现的字，原话照抄）。
- 主人没说、又不影响出图的细节（背景用什么桌面、光从哪边来），丹青替主人定，写进想法里，不问。
- 只有缺了就出不了的才问，而且只问那一项：不知道发哪、做什么用；要放字却没给字。
- 聊天里一句话交代：「我这样理解：……这就出（1 次出图，重画留 1 次）。」然后直接出，不等回话。

## 2. 写提示词
- 照同目录 `借用/图片卡.md` 的骨架（画幅和类型 → 主体 → 动作或状态 → 场景 → 构图和机位 → 光和色 → 风格和质感 → 避免），先过 `借用/规则卡.md`；写成连贯的句子，不堆关键词。
- 出图用 GPT Image（`../paint-master/出图.py`）或 Bot 自带的出图，都是对话式出图：中文写就行。
- 图上要放的字、logo **做图层**（`图类写法卡.md` 最后一节），提示词里写「No text, no logo」，并说清给字留哪块空；主人点名要模型画进画面的艺术字，才把字用引号原样写进提示词。
- 主人给了商品原图（白底图、换背景）：不让模型重画商品，原图抠出来（照 paint-master 母版卡第五节的保底做法）放进新背景，提示词只写背景和光。商品颜色、印花、logo、字一样不改。
- 照需求单卡第六节记一条（`档: 单图`，`想法`、`提示词` 一张一段），跑 `python3 ../paint-brief/check_brief.py <文件>`。

## 3. 出图、查、交
- 出图 → `交付.py` 裁到交付像素、压到大小上限内 → 有字或 logo 就 `叠图.py` 叠上 → 写好 `交付清单.json`，跑 `python3 ../paint-check/check_paint.py <作品文件夹> --brief <单图记录>`，只查机械那几项（像素、比例、大小、白底、张数）。不做母版比对打分。
- 交付照 paint-adjust 第 1 节：图直接发进聊天（8 张以内），第一句讲清规格；**想法和提示词附在图下面**（几行），主人哪里不对一句话改；有字或 logo 才附调图网页。末尾说一句这单实际调了几次出图。
- 不满意：一次只改一处（规则卡「改图」），说清哪些不变；改两次还不对，请主人发一张「像这样」的参考。

## 4. 升档、记住
- 主人说「以后都这样」：把想法和提示词存成配方（paint-library，`我的库/成品/<名>/配方.md`），下回一句话照出，只换要换的部分。
- 主人说「再来几张同一个人的」「要一整套」：转系列图（判档卡第四节），用这张满意的当原型交 paint-master 立母版。
