# 判档卡：这单是单图还是系列图（paint-brief 第 1 步用）

> 卡类：口径｜改了要回归考题

> 主人只提需求，**丹青自己判**：不问主人「要单图还是系列」，回复里也不写「这单走哪档」——「单图」「系列图」「按单张做」「按单图做」这几个词都不出现在给主人的话里，直接说「我这样理解：……这就出」或直接给需求单。判完直接照那一档做——单图交 paint-make 的 `单图卡.md`，梳理想法、写提示词、出图；系列图出需求单（七问）、立母版。

## 一、只看一件事
**这一单的几张图，要不要是同一个人、同一件货？**
- 要 → **系列图**：锁人物、锁商品，才立母版。
- 不要 → **单图**：几张互不相干的图，就是几个单图，各写各的提示词。
- 只要一张、又是主人给的商品原图（白底图、换背景、抠图换场景）→ 单图：原图抠出来用，不立母版。

## 二、信号
| 主人的话、手上的料 | 判 |
|---|---|
| 「一整套」「系列」「全套」「上新主图 5 张」「详情页一组」「几张同一个模特」「分镜」「关键帧」「以后都用这个人／这件货」 | 系列图 |
| 两张以上，里面出现同一个人或同一件货（主人没明说「一套」也算） | 系列图 |
| 记忆里有这件货、这个人的母版，这单又要用它 | 系列图（直接用库里的母版，不重立） |
| 一张图：配图、封面、氛围图、海报底图、头像、表情、客户临时要的一张 | 单图 |
| 「换个背景」「出张白底图」「把这张调亮一点」（主人给了原图） | 单图 |
| 几张图主题互不相干（一张节日海报＋一张公众号配图） | 单图 ×2 |

## 三、例子（只学判法）
| 主人说 | 判 | 为什么 |
|---|---|---|
| 「给这篇文章配张图，讲秋天喝热茶」 | 单图 | 一张，不跟别的图对齐 |
| 「这件开衫上新，主图 5 张」＋一张开衫原图 | 系列图 | 5 张都是同一件货 |
| 「这个模特穿这件，来两张」 | 系列图 | 两张同一个人、同一件货 |
| 「出张抖店白底图」＋原图 | 单图 | 原图抠出来压白，不立母版 |
| 「双十一海报一张，再来一张小红书封面，讲护肤」 | 单图 ×2 | 两张互不相干 |
| 「照这个 MV 拼图，每格都做出来」 | 系列图 | 同一个人贯穿全片 |

## 四、判错了怎么办
- 单图出完，主人说「再来几张同一个人的」「要一整套」：转系列图，用刚才满意那张当原型立母版，说一句「这几张要是同一个人，我先把他立起来」。
- 系列图主人说「不用这么麻烦，就要一张」：转单图，母版不立了，已花的次数照实说。
- 拿不准（比如「两张主图」，没给原图、也没说是不是同一件）：按系列图问需求单里「主体」那一项就清楚了，不另开一问。
