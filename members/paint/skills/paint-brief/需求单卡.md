# 需求单卡（paint-brief 用；paint-make 照单出图）

> 卡类：事实｜核对 2026-10-26｜下次核对 2027-01-24（照官方重核一遍，改了日期跟着改）

> **系列图**一单一张需求单：主人一句模糊的话进来，一轮问完、每项带推荐，主人回「照推荐」「你定」就按推荐定下。需求单定了才建母版、才出图。**单图**不走七问（`判档卡.md`），照第六节记一条就出。

## 一、七问
| # | 问清 | 问法（一句话） | 选项 | 主人没想法时 |
|---|---|---|---|---|
| 1 | **主体** | 「我看这单以商品为主，对吗？」（先自己判断，只让主人点头） | 商品为主／人物为主／人＋货／场景为主／内容为主 | 照第二节判断 |
| 2 | **做什么** | 发哪个平台、这次干什么用？ | 平台：抖店、微信小店、小红书、抖音、公众号、视频号、朋友圈社群；用途：上新、活动、种草、封面、配图、直播 | 视觉档案里的平台和常做的事 |
| 3 | **要什么** | 要哪几种图、各几张？ | 第三节图类菜单 | **只出主人说到的**；再问一句「还要别的吗？」把菜单列出来；要整套才用平台套餐 |
| 4 | **规格** | 尺寸照平台官方，您有别的要求吗？ | 照平台／主人另给 | 照 `~/.yunjian/paint/库/平台规格.md`，不问 |
| 5 | **景** | 白底、棚拍、生活场景，还是您自己的店铺、直播间？ | 白底／棚拍／生活场景／自己的场景 | 从 `~/.yunjian/paint/库/场景/` 挑 2～3 个给主人选（推荐规则卡第三节） |
| 6 | **品牌元素** | 要不要加 logo、宣传语、角标、价格条？您有现成的，还是我出几个方案？ | 加（主人给）／加（丹青出方案）／不加 | 主人没提也要**主动问这一句**；要加又没现成的，从 `~/.yunjian/paint/库/品牌元素/` 出 2～3 个方案 |
| 7 | **参考** | 有喜欢的图、想像谁家的感觉吗？ | 主人给图／从参考库挑／帮我找 | 从 `~/.yunjian/paint/库/参考/` 挑 3 个，附好图标准；要找新的照推荐规则卡第五节 |

一条消息把七问一起列出来，每问后面写上推荐项和一句理由；主人只改他在意的几项，其余照推荐。已经说清楚的那几问不再问，直接写进单子。

## 二、主体怎么判断
看主人的话和给的图，按下面顺序对，对上第一条就停：
| 看到的 | 判成 | 母版建什么（交 paint-master） |
|---|---|---|
| 主人要卖的东西穿在人身上、拿在人手里，或明说「模特图」「上身图」 | 人＋货 | 商品母版＋人物定妆（按品类挑景别：卖上衣以半身为主、卖裤子以下半身和全身为主） |
| 只有商品照片，或说「主图」「白底图」「详情」 | 商品为主 | 商品母版建全（正、背、侧、45°，细节从原图取） |
| 人像、自拍，说「我的封面」「头像」「口播封面」 | 人物为主 | 人物定妆矩阵 |
| 店铺、直播间、门头的照片，说「直播间背景」「店里」 | 场景为主 | 场景建模 |
| 给的是一篇稿子、一个标题，要封面、配图、卡片 | 内容为主 | 不一定建母版；有主人出镜或商品出镜，再按上面补 |
拿不准就写出两种猜法让主人选，不硬判。

## 三、图类菜单
| 图类 | 常见平台 | 规格在 `平台规格.md` 哪节 |
|---|---|---|
| 1:1 主图 | 抖店、微信小店 | 电商 |
| 3:4 主图 | 抖店、微信小店 | 电商 |
| 白底图 | 抖店、微信小店 | 电商 |
| 详情图 | 抖店、微信小店 | 电商 |
| 模特上身图 | 电商主图、详情、种草 | 照它放在哪种图里的规格 |
| 场景图 | 电商主图、详情、种草 | 同上 |
| 细节图 | 电商主图、详情 | 同上 |
| 封面 | 小红书、抖音、公众号、视频号 | 自媒体 |
| 文章配图／信息图 | 公众号、抖音文章 | 自媒体 |
| 小红书图文卡片 | 小红书 | 自媒体 |
| 海报 | 朋友圈、社群 | 没有平台规格，问主人发在哪、多大 |
| 直播封面／直播头图 | 抖音、抖店、视频号 | 自媒体（官方没定统一尺寸） |
- 规格表里标着「待核」的平台（比如视频号）：先跟主人说清这一项还没核对官方规格，停在需求单这一步，不出成品。
- 主人要的东西菜单里没有：照实记下来，写「菜单外」，交 paint-make 时提醒。

## 四、交给主人看的样子（聊天里，八行以内）
```
需求单｜<一句话说这单>
主体：商品为主（看您只给了商品图）——对吗？
做什么：抖店上新
要什么：1:1 主图 ×1（您说的）｜还要别的吗？3:4 主图、白底图、详情图也能出
规格：照抖店官方——1:1 不低于 600×600、5M 以内（出 1440×1440）
景：推荐「白底柔影」，另可选「浅灰无缝」「居家晨光」
品牌元素：要加 logo 吗？抖店官方：主图除品牌 logo 外不建议放字（只提醒，您定）
参考：推荐「正面主图」（首图完整正面实物），另可选「平铺俯拍」「细节特写」
```
这单最多调 5 次出图：成品 1 张、新立商品母版 2 次（母版板 1、改一次 1）、重画留 2 次；超了我先停下问您。回「照推荐」就定。

## 五、存什么（`~/.yunjian/paint/我的库/需求单/<日期>-<一句话>.json`）
```json
{
  "版本": 1,
  "日期": "2026-10-25",
  "一句话": "米白粗针织开衫上新",
  "档": "系列图",
  "锁": ["商品：米白粗针织开衫"],
  "主体": "商品为主",
  "平台": ["抖店"],
  "用途": "上新",
  "要什么": [{"图类": "1:1 主图", "张数": 1, "平台": "抖店", "来源": "主人"}],
  "套餐": false,
  "规格": "照平台",
  "景": {"选": "白底柔影", "来源": "推荐"},
  "品牌元素": {"加不加": "待问", "项": []},
  "参考": {"选": ["ref-zhutu-zhengmian"], "来源": "推荐"},
  "提醒": ["抖店官方：主图除品牌 logo 外不建议放文字"],
  "主人确认": false
}
```
- `来源` 只写「主人」或「推荐」：主人说的照抄，推荐的标推荐，主人回「照推荐」以后把 `主人确认` 改成 true，来源不改。
- `套餐` 只有主人明说「整套」「全套」才是 true。
- 写好跑 `python3 check_brief.py <文件>`，不过不交 paint-make。
- `档` 写「系列图」，`锁` 写这单要锁住的人、货（至少一项；`人物：…`、`商品：…`）——锁不出东西的单子就该是单图。老单子没有 `档` 的按系列图看。
- 演练模式下只打印需求单，不写文件。

## 六、单图记一条（不问七问，出图前写好、跑检查）
聊天里只说三四行「我这样理解」＋「这就出」，不列需求单：
```
我这样理解：一张秋天喝热茶的公众号配图——木桌上一杯冒热气的红茶、旁边几片落叶，暖光、留白多，2.35:1（1880×800）。这就出。
```
存到同一个文件夹（`我的库/需求单/`）：
```json
{
  "版本": 1,
  "日期": "2026-10-26",
  "一句话": "秋天喝热茶的公众号配图",
  "档": "单图",
  "平台": ["公众号"],
  "要什么": [{"图类": "文章配图", "张数": 1, "平台": "公众号", "来源": "主人"}],
  "规格": "照平台",
  "想法": "木桌上一杯冒热气的红茶、旁边几片落叶；暖光、留白多",
  "提示词": ["2.35:1 横版写实摄影……（照 paint-make 借用/图片卡.md 的骨架写成连贯句子）"],
  "提醒": []
}
```
- `来源` 只能是「主人」：单图不加主人没说的图。`提示词` 一张一段。没有 `锁`，有就该是系列图。
- 写好跑 `python3 check_brief.py <文件>`，过了交 paint-make 的 `单图卡.md` 出图。
