# 系列流程卡（判成系列图以后，从头到尾照这张走）

> 系列图要好几轮来回，主人得随时知道到哪一步、下一步该谁做；母版对不对决定后面每张图的质量，所以**母版要主人确认才往下出**。单图不用这张卡。

## 一、进度条（系列图每条回复的第一行，从需求单那条起）
需求单那条就要带，后面每条都带；「好，照推荐定了」这类话放在进度条下面，**不在进度条前面单独先发一句**。
```
系列进度：① 需求单 ⏸ 等您回话 → ② 母版 ⬜ → ③ 定调样张 ⬜ → ④ 出全套 ⬜ → ⑤ 交付 ⬜
下一步：您回「照推荐」或者改哪一项，我就开始立母版。
```
母版那一步的样子：
```
系列进度：① 需求单 ✅ → ② 母版 ⏸ 等您确认 → ③ 定调样张 ⬜ → ④ 出全套 ⬜ → ⑤ 交付 ⬜
下一步：您看一眼三个母版对不对，回「都对」我就出第一张样张。
```
- 符号只用四个：✅ 做完、🔄 正在做、⏸ 等您、⬜ 还没到。
- 第二行永远是「下一步：……」——丹青要做什么，或主人要做什么（回什么）。
- 1～2 张的系列没有定调样张，进度条只写四格：`① 需求单 → ② 母版 → ③ 出图 → ④ 交付`。
- 库里有主人确认过的母版：第 ② 步直接 ✅，写「② 母版 ✅（用库里的）」。主人说「直接出」：写「② 母版 ✅（丹青自查）」。

## 二、五步和三个确认点
| 步 | 丹青做什么 | 主人做什么 | 花几次出图 |
|---|---|---|---|
| ① 需求单 | 七问一轮问完、每项带推荐；写清这单要锁哪些（人物、商品、景）；报上限（`库管.py 上限` 算，算式一起报） | **确认点 1**：回「照推荐」或改几项 | 0 |
| ② 母版 | 每个要锁的对象出一张母版板（paint-master）；先拿身份证自查一遍，不对的自己先重出；再**一条消息把所有母版一起给主人看**（第三节） | **确认点 2**：回「都对」，或说哪一项不对 | 每个母版 1 次，改一项再 1 次 |
| ③ 定调样张 | 3 张以上的系列：用确认过的母版先出 1 张成品，挑最难的那张（人＋货＋景都有的） | **确认点 3**：感觉对不对（光、构图、配色） | 1（算在成品里） |
| ④ 出全套 | 照样张出其余几张；每出 3～4 张更新一次进度条；每张交 paint-check 对母版 | 不用管 | 其余张数 |
| ⑤ 交付 | 发图（8 张以内直接发，多了打包）＋调图网页；母版状态照第四节改；满意的存成配方 | 拖着调，或一句话改 | 改底图才花 |
**出图上限**（第 ① 步报）：成品张数 − 能从原图或母版裁、抠、只排版的张数 ＋ 新立母版个数 ×2（母版板 1、改一次 1）＋ 重画 2；要入库反复用的母版每个再加 3（验收样张）。**不心算**，跑 `python3 ../paint-library/库管.py 上限 5 --不花 2 --新母版 1`，把它打出的算式原样报给主人（「成品 5 张 − 能裁、能抠的 2 张 ＋ 新母版 1×2 ＋ 重画 2 ＝ 7」）。上限以内不再问，超了先停下问。

## 三、母版确认那条消息（主人一眼看完）
```
系列进度：① 需求单 ✅ → ② 母版 ⏸ 等您确认 → ③ 定调样张 ⬜ → ④ 出全套 ⬜ → ⑤ 交付 ⬜
三个母版做好了，请您看一眼，对了我才往下出：
1【商品：米白粗针织开衫】（四面板图）
   不能变的：米白 #ECE2D0｜粗针织｜V 领｜5 颗深棕纽扣｜罗纹袖口和下摆
   我推测的：背面素面、侧缝没装饰
2【人物：模特小林】（定妆板图；人物为主的再附表情板、造型板）
   不能变的：齐肩短发｜黑框眼镜｜偏瘦｜自然肤色（有造型的加：白衬衫＋牛仔背带裙＋白厚底鞋）
   表情：平静、微笑、大笑、惊讶、难过、生气（有表情板才写）
   我推测的：侧脸、背影
3【景：居家晨光】（机位板图）木地板、白纱窗、左边晨光、浅木色家具
下一步：回「都对」我就出第一张样张；哪里不对直接说哪一项（比如「纽扣是 6 颗」），我只改那一项再给您看。
```
| 母版 | 让主人看的 |
|---|---|
| 商品 | 颜色、材质纹理、版型、领口、纽扣和配件数、logo 和印花位置；推测的那几面 |
| 人物 | 脸像不像、发型、身材、肤色、标志物（眼镜、痣、纹身）；推测的角度；有表情板看 6 个表情是不是同一个人；有造型板看衣服鞋配饰对不对 |
| 景 | 光从哪来、色调、主要道具、地面和墙；机位够不够用 |
| 风格／版式（有的话） | 配色、字体、字放哪 |
每个母版只列「不能变的」五六项和「我推测的」，不贴整张身份证。

## 四、规矩
- **主人确认了才往下**：确认点 2 不回话，不出成品；确认点 3 不回话，不出全套。
- **主人回「我看看」「嗯」「等等」**：回一句话（带进度条，不动），比如「好，您慢慢看，看完回『都对』或者直接说哪项不对」；**不只点个表情**，也不往下做。
- **改只改那一项**：主人说哪项不对，只改那一项、只重出那个母版板，再给主人看；同一个母版改两次还不对 → 商品换保底（原图抠图），人物请主人补一张清楚的照片。
- **主人说「直接出」「不用给我看」「你定」**（或视觉档案里记了「母版不用给我看」）：跳过确认点 2、3，丹青照 paint-master 的验收打分表对原图自己验；交付时附上母版板，主人事后能看。
- **母版状态**（身份证卡头）：主人看过说对 → 「主人确认」；主人说直接出、丹青自己验过 → 「丹青自查」；要入库反复用、验收样张也全对 → 「入库」。
- 主人中途改需求（加一张、换景）：进度条退回那一步，说清哪些要重做、多花几次。

## 五、进度存哪（`我的库/作品/<日期-单名>/进度.md`，每走一步改一次）
**不手写，跑脚本**：每发一条带进度条的回复之前，先跑一次（演练模式下不跑）：
```
python3 ../paint-library/库管.py 进度 2026-10-26-米白开衫主图5张 --现在 "② 母版 ⏸ 等主人确认" --母版 "商品 米白开衫（草稿）｜人物 小林（草稿）" --出图 3/13 --下一步 "等主人回「都对」" --等主人定 "三个母版对不对"
```
主人改了哪项、出了哪张，加 `--记 "纽扣改 6 颗，商品身份证 v2"`，会追加进「经过」。没变的项不用再写，脚本留着上回的。缺「现在」「出图」「下一步」、出图次数写不成「3/13」会报错；出图超上限会提醒先停下问。
写出来的样子：
```
# 进度｜米白开衫上新主图 5 张
现在：② 母版 ⏸ 等主人确认
母版：商品 米白开衫（草稿）｜人物 小林（草稿）｜景 居家晨光（草稿）
出图：3/13
下一步：等主人回「都对」
等主人定：三个母版对不对

## 经过
- 10-26 14:02 ① 需求单 ✅
- 10-26 14:10 ② 母版 ⏸ 等主人确认
```
主人隔天回来、换了窗口、问「做到哪了」：先跑 `python3 ../paint-library/库管.py 没做完` 找没交付的单，再 `库管.py 进度 <单名>` 读出来，回进度条＋下一步，接着做，不从头问。演练模式下只打印，不写文件。
