# 出图自检

**单图**（记录里 `档: 单图`）只过第 1 道机械的；没有母版，不做第 2 道的母版比对，但图上的字照样一字一字对、商品原图抠出来的不许被改。

## 1. 机械的：跑脚本
- 作品文件夹里写 `交付清单.json`（每个文件：第几张、平台、图类；主人另给了像素就加「像素」），跑：
  `python3 check_paint.py <作品文件夹> --brief <需求单.json>`
- 脚本查：像素（交付像素或主人给的）、比例、官方下限上限、文件大小、白底四角、张数（少了、多了都算错）；规格表里没有的平台图类（待核）直接停。图层文字里的极限词、联系方式会提醒。
- 硬的是平台官方规格；和丹青默认交付像素不一样只提醒（主人自己的图官方能传就说能传，不拿丹青的默认卡人），主人明确要了某个像素才必须一样。
- 不过：尺寸、大小的问题回 paint-make 的 `交付.py` 重裁重压；张数多了删掉多的那张，不交。

## 2. 看图的：逐张对
让会看图的模型把成品和母版板、身份证并排看，每项只打 1 或 0、写看到了什么：
| 项 | 1 分的样子 |
|---|---|
| 对母版 | 照 paint-master 的 `验收打分表.md` 那种母版的几项（颜色、形状、印花和 logo、材质、配件数、没编东西；人物是同一个人）。**带印花的商品**：从原图和成品各裁同一块印花、并排拼一张自己看（多颜色的每张都拼），形状、元素个数、颜色、字有一处不同就是 0，不算小偏差 |
| 字 | 图上每个字和图层、需求单、主人原话一字不差；底图里没有模型自己画出来的字、乱码、水印 |
| 主体完整 | 商品没被裁掉、没被字和 logo 挡住；人脸没被压 |
| 平台硬规矩 | 抖店首张是完整正面实物（主人选了「先出效果图、不上架」的这项不扣，交付写明不能上架）；白底真白；公众号封面 1:1 那一裁里主体和标题完整 |
| 与实物一致 | 没画商品没有的效果（更亮、更挺、多一个口袋），没做假的买家秀 |
有一项 0 就回 paint-make 重出那一张（改提示词，把出错那项写得更具体），最多 2 次，算进这单的出图上限、用完先问主人；还不过：交付时照实说「第 3 张印花还是小了一圈，换保底做法要不要」，不硬交。

## 3. 只提醒的（附出处，主人定）
- 平台对字的要求（`~/.yunjian/paint/库/平台规格.md`）：抖店主图除 logo 外不建议放字、抖音封面字占比小于 30%、小红书文字不遮挡重要内容、微信小店字别被截断。
- 极限词、联系方式（脚本提醒的）。
- AI 生成的图：发布时按平台要求标注（《人工智能生成合成内容标识办法》）。

## 4. 写自检记录
在作品文件夹写一份自检记录（`作品/<单名>/自检.md`）：机械的结果一行、看图每张一行（项和分）、提醒了什么。交付时聊天里只说结论一句（「都过了」或「第 3 张……」），不铺过程。演练模式下只打印。

## 不做
改图（交 paint-make、paint-adjust）；替主人删改设计；正式的法律审核。
