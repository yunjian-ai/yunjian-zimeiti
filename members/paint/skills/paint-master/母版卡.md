# 母版卡（paint-master 用；paint-make 出图时照这里取母版）

> 母版是丹青的命根子：同一件商品、同一个人换多少张图都还是它，以后做视频也直接用这套。**主人只给原型（一张模特图、一两张商品图），母版是丹青自己做出来的**，不向主人要各角度照片。

## 一、八种母版，一个样子
| 种类 | 管什么 | 母版板怎么拼 | 身份证「不许改」重点 |
|---|---|---|---|
| 商品 | 这件东西长什么样 | 白底：正、背、侧、45° 一张四格板；细节特写另放 `单张/` | 颜色（色号）、材质和纹理（针数粗细）、形状比例、印花和 logo 的位置大小、包装上的字、配件数、纽扣数 |
| 人物 | 主人、模特、IP 长什么样 | 定妆矩阵（第三节）：打底板（上半身组、全身组、下半身组各一张四格板）；人物为主、IP、视频角色再加**造型三视图**、**表情板** | 脸型、五官、发型发色、肤色、年龄感、身高身形三围、常穿码数、标志物（眼镜、发箍、痣）；有造型的加造型 |
| 场景 | 店铺、直播间、家里某个角落 | 同一场景 4 个机位一张四格板（要细再做 9 格） | 空间结构、固定陈设的位置、主色、窗和光源方向 |
| 风格 | 一个号、一个店的调性 | 主人认可的 2～3 张代表图，不另生成 | 主色 3～5 个（色值）、画法、质感、氛围词、不要的东西 |
| 品牌 | logo、品牌色、字体、标语 | logo 原件（透明底最好）＋色卡＋字体名，不让模型画 | logo 不变形不改色、品牌色色值、字体名、标语原文 |
| 版式 | 字和图放哪 | 一种图一个网页模板（拖着调用），交 paint-adjust | 各区块位置比例、字号层级、安全区 |
| 服装道具、光影镜头 | 人物常穿的、手里常拿的；光从哪来、机位焦段 | 一期记在人物、场景的身份证里，做视频前再单独立 | 颜色款式；主光方向、软硬、色温、焦段 |

每个母版一个文件夹：
```
~/.yunjian/paint/我的库/母版/<种类>/<名字>/
├── 原件/        主人给的原图，原样不改
├── 母版板.png   标准参考图（多角度／多机位拼一张）；人物这张是打底板
├── 造型板.png   人物才有：穿固定造型的全身正、侧、背（有造型才做）
├── 表情板.png   人物才有：6 个表情两行三格（人物为主、IP、视频角色才做）
├── 单张/        母版板拆开的每一格、细节特写；出图时按需挑几张喂给模型
├── 身份证.md    照 `身份证/<种类>.md` 写
├── 样张/        验收出的 3 张（只有要入库的才有）
├── 验收.md      照 `验收打分表.md` 打的分
└── 版本.md      v1、v2……每次改了什么、为什么；旧版留在 `旧版/vN/` 能退
```
写完跑 `python3 check_master.py <母版文件夹>`。

## 二、这单建哪几个（看需求单的主体，只建用得到的）
| 主体 | 建什么 |
|---|---|
| 商品为主 | 商品母版建全；人物不建（除非要上身图） |
| 人物为主 | 人物定妆矩阵建全：打底板＋表情板；有固定造型（出镜常穿、IP 服装、视频角色）再加造型三视图 |
| 人＋货 | 商品母版＋人物定妆，景别按品类挑：卖上衣以上半身为主，卖裤子、裙子以下半身和全身为主，套装用全身 |
| 场景为主 | 场景母版建全 |
| 内容为主 | 一般不建；有人或商品出镜再按上面补 |
品牌母版：需求单里要加 logo、品牌色的，第一个立（最小、最快，后面每张都用）。风格母版：主人给了参考图或说「以后都这个感觉」才立。
**先查库**：`我的库/母版/` 里有同名、同款的，直接用，告诉主人「用的是上回立的某某母版 vN」。

## 三、人物定妆矩阵
| 维度 | 一期做 | 用在 |
|---|---|---|
| 景别 | 脸部特写、上半身（到腰）、下半身（腰到脚）、全身 | 按品类挑（第二节） |
| 角度 | 正面、45° 侧、90° 侧、背面 | 主图多角度、详情看版型、背后设计 |
| 姿态 | 自然站立（必做）；手插兜、抬手、走动、坐姿（要用时补） | 主图动感、短视频起始和转身 |
| 表情 | 电商模特：平静（必做）；微笑、不看镜头（要用时补） | 上身图、种草图 |
| 造型三视图 | 穿这个人物固定那身衣服、鞋、配饰：全身正面、侧面、背面三视图一张板 | IP、出镜形象、视频角色，衣服本身就是人物的一部分 |
| 表情板 | 胸像、素色打底、同一光，6 格两行三列——平静、微笑、大笑、惊讶、难过、生气 | 封面、种草图、视频里换表情脸不走样 |

**做哪些，丹青照这张判，不问主人**（规划书 v1.6 决策 46）：
| 这单的人物 | 做 |
|---|---|
| 电商模特（穿商品上身） | 打底板（下面三组按品类挑）；表情只用平静、微笑，不出表情板 |
| 人物为主：主人出镜、IP 形象、封面人物、要做视频的角色 | 打底板＋**表情板**；有固定造型的再加**造型三视图** |
| 主人说「以后做视频也用她」「做成一套」 | 上面全做，母版按「入库」走 |
- 打底板：上半身组、全身组各一张四格板（正、45°、90°、背），卖裤裙再加下半身组；人物为主的只做全身组就够，要特写再出脸部特写。
- 表情板、造型板各算一个新母版板（出图上限里各 ×2）；主人确认母版时三张板一起给主人看。
- 打底板、表情板一律穿**贴身的中性打底**（纯色、没图案），同一均匀光；换装时才不会把旧衣服的图案带进新商品。造型板才穿那身固定造型。
- 身份证里写身高、三围、穿什么码（主人给的照抄；原型看出来的标「推测」），上身图的版型才对得上尺码表。

## 四、立母版五步
1. **收原型**：人物一张清楚的正面或半身图；商品一两张主人现成的图（主图、平铺、上身都行）。**不向主人要更多角度。** 原型糊到看不清脸或商品细节，说清哪里看不清，请主人换一张，只这一次。
2. **生成母版板**：照 `写法卡.md` 对应一节出图（引擎见 `出图.py`；Bot 里没设密钥就用 Bot 自带的出图）。**细节特写不生成，从原图裁**：`python3 细节.py <原图> --box 左,上,右,下 --out 单张/细节-领口.png`，必要时模型只做清晰化、不改内容。
3. **标推测**：原图里看不到的地方（背面、侧缝、鞋），模型生成的都是推测，**默认按素面、最保守的样子画**，写进身份证「推测」一节。电商图不能编商品没有的东西。
4. **写身份证**：让会看图的模型照 `身份证/<种类>.md` 看原型写初稿，丹青挑出「不许改」的项；主人给的数字（三围、码数、成分）照抄，看出来的标推测。
5. **先自查，再给主人确认**：拿身份证「不许改」对着母版板逐项看，不对的先自己重出；再把这单所有母版一条消息给主人看（paint-brief `系列流程卡.md` 第三节），**主人说对才往下出**，状态改「主人确认」。主人说「直接出」：照 `验收打分表.md` 对原图自己验，状态改「丹青自查」。**要入库反复用的**：主人确认后再换 3 个不同场景各出 1 张样张、逐项打分，全对状态改「入库」（不对回第 2 步重出，每轮前先看出图上限，最多 3 轮，还不过换保底并告诉主人卡在哪）。

## 五、保底
商品母版三轮验不过（颜色、印花、纽扣总走样）：改用**原图抠图＋模型只画背景和光影**，商品像素原样不动，电商图永远不走样。告诉主人这几张是保底做法、换场景的自由度小一点。

## 六、改母版
主人说「颜色不对」「她没戴眼镜」：只改那一项，身份证升一版，旧版挪进 `旧版/vN/`，版本.md 记一行；改完重新验收那一项相关的样张。主人说「以后都这样」才升版，一次性的改动只改这一张图，不动母版。
演练模式下只打印母版板和身份证，不写进我的库。
