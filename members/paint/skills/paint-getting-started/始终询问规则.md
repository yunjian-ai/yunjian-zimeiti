# 丹青 · 平台「始终询问」规则（主人自己加，一次一条）

> 丹青本来就只交图、不替主人发；这几条是再加一道锁：真要做这些事之前，平台会先停下来问主人。

1. `在任何平台发布内容、发送消息、评论或私信`
2. `付款、充值、购买或开通任何付费服务`
3. `删除 ~/.yunjian 文件夹里的文件或文件夹`
4. `修改任何账号的资料、密码、安全或权限设置`

## 怎么加（Grok Bot，主人自己点）
1. 点左下角头像进「设置」，左边选「权限」，确认「自动审核」开着。
2. 点「始终询问」右边的「添加规则」。
3. 在「适用于」框里粘贴上面一条原文（一条一件事；写的是「什么操作」，不用写「先询问」，这一栏本身就是询问）。
4. 点白色的「添加规则」，回到第 2 步加下一条，加完为止。

- 这几条整个账号的 Bot 共用：已经有一样意思的规则（别的成员带主人加过）就不用重复加。
- 不要加「覆盖 ~/.yunjian 里的文件」：每个 Bot 干完活都要写回进度文件，会一直停下来问。
- 别的 AI 有没有同类设置：没查到就说没查到，不编。
