# 配图和画面方案

## 0. 开工前
读 pen-draft 的 `规则卡.md`、`平台卡.md`（封面尺寸、导流），库 `平台/<平台>/规则.md` 的「封面和画面」，和这篇稿子、抽到的爆款卡「图文和画面」一节（pen-library）。记忆里的「作者档案」有品牌色、字体、出镜习惯就照用；「视觉」一项还没问过：**先按默认（大号粗体字配一个主色）把完整方案出了**——方向、封面文字、画面框架、提示词或制作单一样不少——同一条回复末尾只问一句视觉偏好（pen-getting-started 第 6 步），主人答了再按他的改；不许只问不出。

## 1. 先挑哪些话用图说
逐段看，下面五类做成图或表，正文只留一句：**数字对比、前后对比、步骤、清单、价格账**。收藏件一定做成图。每张图写清对应正文第几段、图上放哪几个字。

## 2. 封面
- 尺寸照平台卡（公众号 2.35:1 再裁 1:1，小红书 3:4，抖音、视频号竖版 9:16，X Article 5:2，知乎、微博 16:9）。
- 粗重字体、大字，主标题最多两行；重点放中间偏上，避开平台盖字的地方。
- **封面上的数字、结果和正文一字不差**；不写正文没有的承诺。
- 出 2 个方向（比如「大数字」和「前后对比」），推荐 1 个说为什么。

## 3. 文章配图和表格
长文稿里的 👇【图】【图表】【视频】图片位（`pen-draft/形式卡.md` 第二节）就是配图清单：一个图片位出一张，编号照稿子的顺序；每张做成**带标注**的样子（图上标题、前后数字、箭头或分区说明），不是随手截图；图上的字和数字跟正文一字不差；主人拍不到的，用图片位里「没有就」那一项（示意图、数字卡、表）。
- 每张图：位置（第几节后）、类型（信息图 / 截图 / 实拍 / 表格）、图上文字、要突出的那个数。
- 表格框架：标题、列名、几行；格子里的内容出自料，没有的标【问】，不替主人填。

## 4. 口播的画面框架
口播稿每段段头已经带了〔画面或道具 · 动作 · 语气〕（`pen-draft/形式卡.md` 第一节），这里只在主人要更细的镜头时出下面这张表，段和稿子的段一一对应、编号相同，不另起一套。
按稿子分段（对齐钩子链）：
```
段｜时间｜口播要点｜画面（实拍 / 屏幕录制 / 字幕卡 / 图）｜字幕重点（≤8 字）
```
- 封面帧：选最有冲击的那一句（通常是爆点或开头钩）。
- 要实拍的写清拍什么、几秒；主人没有的素材标【问】。

## 5. 禁导流和合规
抖音、视频号、小红书、微博、知乎：图里不放二维码、链接、网址、联系方式、价格；带货图不写极限词、功效承诺（规则卡第 8 条）。水印、文件名也查。

## 6. 交出去的三种方式（至少给一种）
1. **会出图**（环境里有画图工具）：直接出，交图并说明每张对应哪段。
2. **给提示词**：每张图一段提示词（画面、构图、文字内容、风格、尺寸）；图上的中文字单独列出，提醒主人画图工具常写错中文，字最好后期加。
3. **制作单**（交给别的 Bot、设计师或团队）：
```
制作单｜稿子：标题｜平台：…
序号｜用途（封面 / 配图 / 收藏件 / 画面）｜尺寸｜图上文字（一字不差）｜重点｜参考（爆款卡 id 或描述）｜注意（禁导流、数字核对）
```
演练模式下只打印。

## 7. 交什么
```
用图说的段落：第 N 段（数字对比）…
封面：方向 A …｜方向 B …｜推荐 …，因为 …
配图 / 表格：…
口播画面框架：（表）
交付方式：出图 / 提示词 / 制作单
核对：图上数字和正文一致 ✓｜禁导流 ✓
```
做完交给 pen-check。

## 不做
不编图上的数据；不用别人的图冒充主人的实拍；不替主人发布。
