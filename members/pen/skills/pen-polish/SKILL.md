# 改稿

## 标准
- 衡量只看一条：**像不像主人本人**。只把像 AI 的句子删掉，得到的是挑不出错、可也不像任何人的稿子；还得把只有主人才说得出的东西放回去，**放的只能是档案里本来就有的**：主人的原话、主人算过的账、栽过的跟头、常说的那几句。
- AI 味从哪来：说话的架势不对——居高临下，先替观众把问题想好，再端出一个标准答案。把架势放平，多数毛病跟着就没了。
- **口吻档案的保留清单说了算。** 清单上的习惯，后面哪条规矩都删不得。
- 补样稿原话时一句一句补，带「这个方法」「那次」的句子不挪到别的事后面，免得拼成新事（`写法卡.md` 第三节）。
- **先有人话的样子，再查 AI 味**：人话的八个维度和换的顺序在 pen-draft 的 `人话卡.md`；七组 39 项、翻案腔外衣表、放过和要保护的、改稿底线在 `去AI味卡.md`，当改完后的复查清单。

## 0. 开改前
读 `人话卡.md`、`去AI味卡.md`、`写法卡.md`、`形式卡.md`、`规则卡.md`，库 `表达/`（行业说法、流行语；读不到就跳过这一层），和记忆里的「作者档案」「口吻档案」。
- 从 pen-draft 过来的：默认深改，按母版改，不问平台。
- 主人单独拿稿子来改：主人说「深改」「要像我」「大改」走深改；只说「顺一顺」「改改」走轻改，默认轻改，说一句「先轻改，要更像您可以深改」。只改某个平台的版本时，才问是哪个平台。
- 要改成口播：先做第 3 节，再去 AI 味。

## 1. 先列原文要点
把原文的要点逐条编号（几个观点、几个数字、几个例子、几处限定：可能、计划、超过、据说）。改完逐条对一遍，一个不丢；原文没有的事实一个不加。**空话不算要点**：原文的升华、三连排比（「是对 A 的尊重，是对 B 的珍惜……」）、空承诺直接删，不换个说法再写一组三连；真有的意思并成一句说。**样稿原话搬进来时看指代**：样稿里指代不清的话（「这个方法我用了两年」），别接在会被当成某个具体做法的位置，放不准就标【问：指的是哪个方法？】。

## 2. 逐句扫（只标位置，先不改）
照 `去AI味卡.md` 第二节七组逐句扫，标组号和级别（必改 / 看情况），回上下文判断；放过和要保护的照第三节。能跑程序就先跑 `check_pen.py`（稿子写 `-` 从标准输入给）。

## 3. 书面改口播（要改成口播时）
照 `形式卡.md` 第一节：长句拆短（一句不超过 25 字），拆的时候顺着说（谁、干了什么、结果），不把东西提到前面再加逗号（`人话卡.md` 第零节）；书面词换口语（「综上所述」「值得注意的是」「首先其次再次」全换）；按念的顺序重排，`/` 标停顿、加粗标重音；结尾换成一个互动问题。有时长要求的按时长算字数，原文太长先删重复的，不删要点。

## 4. 事实核对（两档都做）
- 每个数字、每件事、每个判断都要对得上素材库、样稿或本次对话；对不上的标出来。
- **主人拿来的稿子里的具体事实就是主人的料**（年限、数字、做过的事，比如「我做收纳 4 年」），照留，不改成【问】；要删的只是说不出来源的概括、归因和道听途说（「见过太多这样的家庭」「大部分人都会」）。
- 遇到数字，先拿主人给过的数算一算：算得出，标 `【推算】`，把算式和用到的假设写出来，问主人能不能这么用；假设站不住就改成【问】；怎么都算不出，那就是编的。
- 说不清从哪来的标 `【问：…】`；宁可删了，也不让一个假数字留在稿里。
- 改稿全程**一样都不添**：事实、数字、动作、感受、原因、概括。

## 5. 两档怎么改
**轻改**（快，主人急着要时用）：只动「必改」的和事实有问题的，骨架、段落先后都不碰。每一处这样改：先弄清这句本来要说什么，再用主人平时会说的大白话直说，别换一个更花哨的句式顶上。
**深改**（七步，只写在这里）：
1. 先做轻改的全部；
2. 把稿子当别人写的：先抽出它说了哪几件事，再照 `写法卡.md` 重新说一遍，不在原句上换词；
3. 逐段问「这段换个人也写得出来吗」：写得出来的，从素材库和样稿里找主人自己的料补进去，按档案规定的位置和频率用，连「几天」「几次」这种小数字也要有出处；找不到就把这段删短，问主人一个具体问题（「这里您当时是怎么做的？」），答了才补，**绝不为了让段落饱满去编细节，样稿里的试写也不算出处**；补主人的话不把别处的事挪成这篇里发生的事；
4. 照 `人话卡.md` 第一节八个维度逐段对照，按第二节的顺序换（口吻档案 → 行业说法 → 平台表达 → 通用口语），每处注明来自哪一层；按口吻档案调节奏：句长、段长、标点、自称；补了料超字数，先删重复的强调和过渡；
5. 删掉正确的废话段落，删了意思不少就留删短的；
6. 结尾删掉最后一段试读，删了更好就删；结尾不拔高，落在一个动作、一个数字或主人的一句话上；
7. 口播照 pen-draft 第 3 节「先念一遍」的六样（人称、顺着说、口头禅位置、转述说全、前后句接得上、不拗口）逐段念，换气卡嘴、接不上的地方改掉。

## 6. 改完自检
照 `去AI味卡.md` 第五节：再扫一遍、再问一轮「还有哪里像 AI」（只再改这一轮）、对出处、对第 1 节的要点和限定、保留清单、冷读。

## 7. 交什么
**先交改好的全文**：口播和几百字的短稿直接放聊天（口播附字数和时长），长文当附件发（pen-draft 的 `成品卡.md` 第 2 节），不铺进聊天；再一两句说改了哪几类、最多 3 条「要注意的」；下面这份放进 「自查记录」文件（不能建文件就放在最后、标「自查记录（不用看）」），主人说「看看改了哪」才贴（pen-draft 的 `成品卡.md` 第 4 节）。在成品里跑的（从 pen-draft、pen-remake 过来），这一步不单独交，直接接 pen-cover。
```
改的档位：轻改 或 深改｜平台：母版 / …
毛病清单：第 N 段「原句」｜组号｜必改 / 看情况
事实核对：【推算】…（算式、假设）【问】…
改后全文
改了哪几处：原句 → 新句｜组号 / 人话卡维度｜层：口吻档案 / 行业说法 / 平台表达 / 通用口语
补进的主人料（深改）：「…」出自素材第 N 条 / 样稿第 N 段 / 本次对话
要点核对：原文 N 个要点、N 处限定，都在 ✅
故意没改的：「…」｜理由
自检：七组复扫 ✓｜保留清单 ✓｜无新增事实 ✓｜句长：…
```
初稿本来就干净（没有必改项）时，交简版：问题清单、改了哪几处、核对一行。口播稿附字数和预计时长。单独改稿的，改完自己照 pen-check 过一遍，结论写一行，不问「要不要出平台版」。演练模式下照常交，不写记忆。

## 意外
- 原文里有编出来的数字、极限词、功效承诺：不替它圆，标出来，照 `规则卡.md` 第 1、8 条处理，交稿时说清。
- 主人只说「这句不像我」：只改那一句；主人说的是习惯（「我从来不说某某」），同时照 pen-voice 第 5 节改档案。

## 不做
不新增事实；不把「可能」改成「一定」；不重写成另一篇；不替主人发布。
