# 钩子卡：标题、第一句和全篇钩子链

> 给人看：九成的人前 3 秒就划走，文章是前三行定生死；留住之后，每一段都要再给一个往下看的理由。这张讲怎么从料里找开头、写标题、把钩子一个接一个串到底。
> 给 AI：pen-angle 搭骨架、pen-title 出标题、pen-draft 出稿、pen-remake 仿写、pen-check 查钩子链时用。

## 一、先找料（五样）
从主人给的料里逐条找，标出是哪一条：
1. **硬数字**：一天报废 40 个、半小时变 5 分钟；
2. **转折**：以为……结果……；
3. **立场句**：主人自己下的判断（「便宜的锅反而好用」）；
4. **资格**：主人凭什么讲（干了几年、带过多少人——只用主人说过的）；
5. **处境**：观众此刻正卡在哪（用观众会说的话）。
五样里任意 3 样就够；料里有的就用（资格进了标题，开头也能用），没有的不硬凑；不到 3 样先问料。

## 二、开头 3～5 个
- 每个开头注明用了哪样料（如「硬数字＋转折，出自料第 2 句」）。
- 每个过五条：①第一句就有具体东西 ②不铺垫（不说「今天跟大家聊聊」）③观众听得出跟自己有关 ④主人说得出口（对照口吻档案）⑤没有料外的事实（时间、次数、「一年前」「第一次」也算事实）。
- 推荐 1 个，说为什么。

## 二½、口播钩子类型（前 3 秒，每个 ≤18 字，第一个画面是商品或痛点）
痛点提问（你是不是也……）、结果先行（先给结果画面再解释）、数字、场景代入（当你在……的时候）、错误示范（别再这样做了）、对比（左边普通款、右边这个）、第一人称（我换了三个，最后留下这个）、坦白（说实话我以前也觉得……，后半句立刻接证据）、留悬念（选……看这 3 点，第 3 点最多人忽略）。反差只用外观和实测的真反差，不用「你以为……其实」。每个钩子里的数字、效果都要是主人测过的。

## 三、标题三公式（各出一个）
- **悬念**：留一个问题不说破（「天天加班还做不完？我先砍掉了一件事」）；
- **数字**：具体数字打头（「一天扔 40 个面包，我只改了一个时间」）；
- **反常识**：和大家以为的反着来（「新手别先买贵的锅」）。
标题是广告不是说明书：说观众能得到什么，不概括全文。标题里的数字也要出自料。

## 四、全篇钩子链
- **每一段＝钩子 → 兑现 → 引出下一个钩子**。钩子五种：抛问题、悬念、反差、利益、冲突。兑现用事实（标料号）加手法（写明用了哪种）。抛出来就要接得住：正文接不住的钩子是骗点击，不许用。
- **四个点要标出来**：
  - **重点**：观众要记住的那一句；
  - **爆点**：最想转、最意外的那一下，一篇至少一个；
  - **槽点**：能引评论的真问题或真争议（比如「你们店是早上做还是晚上做」），不编争议、不挑事、不拉踩；
  - **知识点**：观众能学走的东西（步骤、数字、判断方法）。
- **60 秒口播的样子**：0～3 秒开头钩 → 每 10～15 秒一个小钩（新事实、反转、一笔账）→ 40～55 秒爆点 → 结尾用槽点引评论。更长的口播照这个节奏往后延，每段都要有新东西。
- **长文的样子**：标题钩 → 首段钩 → 每个小标题本身是钩 → 中段放收藏件 → 结尾钩（槽点或行动）。
- **帖子串的样子**：第一条是总钩（整串给什么）→ 每条一个点、末句引下一条 → 最后一条给动作或收藏件。
- **参照爆款**：库里抽到的爆款卡有「钩子链」一节，照它的**位置和节奏**搭，每一步换成主人的料；不搬它的句子和事实。
- **交出来的样子**（pen-angle 写进骨架，pen-draft 写进出处表下面）：
```
钩子链：①0～3 秒｜钩：…（类型）｜兑现：…（料几，手法）｜引出：…
        ②…
重点：…｜爆点：…（第几段）｜槽点：…｜知识点：…
```
