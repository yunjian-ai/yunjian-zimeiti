# 形式卡：平台定形式，口播写给耳朵，长文写给眼睛

> 给人看：先定发哪个平台，再按这个平台什么形式容易爆来定写口播、长文还是帖子；同一份料，念的和读的写法不同，底子都是真料、主人口吻、钩子不断、不编。
> 给 AI：pen-title、pen-angle、pen-draft、pen-polish、pen-remake、pen-platforms、pen-check 照这张。

## 〇、平台定形式
1. **先定平台**：作者档案里选了的平台；这次没说就问一句「发哪儿」，主人说「都要」就先写主平台，其余交 pen-platforms。
2. **按库定形式**：读库 `平台/<平台>/规则.md` 的「什么形式爆、多长」，推荐一种形式并说依据（比如「抖音 AI 应用的爆款口播时长中位约 6 分钟，样本 20 条」）；作者要换就换。
3. **读不到库**用这张默认表，并告诉主人「这次没用上平台打法库」：

| 平台 | 默认形式 | 默认长度 |
|---|---|---|
| 抖音、视频号 | 口播 | 60～90 秒；干货讲透可以 3～6 分钟，前提是每段都有新东西 |
| 公众号 | 长文 | 复盘、方法 1500～2500 字；观点 1000～1500 字 |
| X | 单帖或帖子串；长的写 Article | 单帖一个点；帖子串 4～10 条 |
| 小红书、知乎、微博、抖音长文 | 长文或图文 | 照 `平台卡.md` |

## 一、口播
- **时长换算**：每分钟 220～260 字。字数 ≈ 秒数 × 220～260 ÷ 60：30 秒 110～130 字，60 秒 220～260 字，90 秒 330～390 字，2 分钟 440～520 字。主人没说时长，照第〇节按平台和库定，库读不到默认 60～90 秒。交稿写「约 N 字，预计 M 秒」；字数落在上面的范围里，范围本身就是快慢的上下限，不再放宽。字数用 `check_pen.py` 数：汉字、字母、数字各算一个，标点和 `/` 不算，口播只数各段段头下面的台词（交稿头、借用单、出处表不算），长文数到单独一行 `---` 为止（不用建文件，整条交稿从标准输入给就行，见 pen-draft 第 4 节）；跑不了就逐行数，写「约 N 字（手数）」，不估。各平台都按同一个语速换算：节奏要放慢，就少写字，不改换算。
- **料撑不住时长**（够不上 `写法卡.md` 第二节门槛，60 秒不到 4 件料）：先问（最多 3 问），或建议缩短，说清「这些料够 N 秒」；不注水。过了门槛就按时长写满，不写短。
- **能念**：一句不超过 25 字（按念的一口气算：逗号、句号、问号、`/` 都算断开，和 `check_pen.py` 同口径），超了就断开；书面词换口语（「综上所述」→「所以啊」，「值得注意的是」→「你注意」）；念起来拗口的词换掉。
- **排版（杨先生 10-24 定：台词占主位，提示不压台词，一眼找到重点）**：按骨架分段，每段一个段头，段头带色块、编号、环节名、秒数，后面〔画面或道具 · 动作 · 语气〕一句提示（≤12 字），台词里一个提示字都不放；台词一口气一行（15 字左右，在逗号处换行），段与段空一行；`==…==` 标重点句和字幕词（每段最多一处），`**…**` 标要重读的数字和词；开头一行写「约 N 秒｜要准备：道具」，道具只写料里真有的，主人不一定拍得到的镜头写「要拍：…／没有就：近景口播加字幕」。色块按段轮：🟥🟧🟨🟩🟦🟪。
- **骨架**：口播不按时间顺序讲，走「钩子 → 冲突 → 戳观众 → 转折 → 结果 → 收尾引导」（`钩子卡.md` 第四节）；前 3 秒要过划走测试（`钩子卡.md` 第二节）。
- **结尾**：照 `钩子卡.md` 第五节给收尾引导：好回答、和观众自己有关的评论问题，或说清理由的收藏，料里真有下一条才提关注；不空喊「点赞收藏关注」，不拔高；带货稿的行动（怎么试、先买哪个）放在正文最后一句，再接引导。
- **交稿样子**（这份文字本身就是纯文字版；能跑程序就再用同目录 `提词卡.py` 转成彩色提词卡网页一起交：`python3 提词卡.py 稿子.txt`）：
```
标题：…
约 60 秒｜要准备：…（料里真有的道具）

🟥 ① 钩子 0～3″〔画面或道具 · 动作 · 语气〕
台词一口气一行，
重点句写成 ==…==，数字写成 **…**。

🟧 ② 冲突 3～15″〔…〕
…
🟨 ③ 戳观众 …〔…〕
🟩 ④ 转折 …〔…〕
🟦 ⑤ 结果 …〔…〕
🟪 ⑥ 引导 …〔…〕
…（收尾引导：评论问什么／收藏的理由）

约 N 字，预计 M 秒｜稿型：…｜推算：…｜待问：…
出处：每句带事实的 → 料几
```
（段名跟着骨架走：带货走五步就写五步的名；时长短的可以并段，但钩子和引导两段不能少。）

## 二、长文
> 杨先生 10-24 定：照三篇标杆（`资料/执笔/15-长文排版标杆拆解.md`，开发仓库）定版式；重点一眼看得到，钩子、论点、证据、槽点、图片位分得清，长文才活。
- **篇幅**：按料估，每条真料约 120～150 字；复盘、方法型 1500～2500 字，观点型 1000～1500 字；不超目标平台上限（`平台卡.md`）。料少就写短，告诉主人「料只够这么长」。
- **标题**：数字 ＋ 读者拿走的东西 ＋ 门槛低（「衣柜 3 平米塞了 41 件外套：这 3 步（附一张能打印的清单）」）；系列写「（上篇）（下篇）」。标题最后取，从正文写实的地方里找。
- **开头四件套**（前 5 行）：①钩子：第一句就是料里观众最有感的痛、反差或前后对比（过 `钩子卡.md` 第二节的划走测试）；②一句槽点或戳读者（「你家是不是也这样？」）；③这篇给你什么：列出读者能拿走的两三样东西，接「建议先收藏」；④目录（三到六条）。不说「今天跟大家聊聊」「我将从三方面讲」这种空预告——列的是读者拿走的东西，不是作者要讲什么。
- **骨架两级编号**：大章「一、二、三」，小节「1.1、1.2」。每个小节固定顺序：一句结论（论点）→ 证据（料里的真事、数字）→ ★ 步骤（一步一行）→ 💡 小技巧 → ⚠️ 坑；用不上的那项不硬凑。小标题只用来定位，不提前写结论；各节不必等长。
- **固定符号**（读者扫一眼就知道是什么，整篇只用这几种）：★ 关键步骤；💡 小技巧；⚠️ 坑；👇 下面有图、表或视频；【可以直接抄】能直接复制的话、提示词、模板（单独一个框）。
- **字的变化**：`==…==` 黄底标重点句（每节最多一两处）；`**…**` 红字标数字和要重读的词；小节结论句可整句加粗。
- **图文**：每个大章至少一个 👇 图片位；图前先用一句话说「这张图看什么」；图要做成**带标注的**对比板、流程图、截图或表（标题、前后数字、箭头），不是随手贴。图片位写清「要拍：…／没有就：…」（主人不一定拍得到，给替代：示意图、数字卡、表）。视频和图表同样写成 👇【视频】👇【图表】。
- **收藏件**：至少一个能存下来反复用的东西（清单、速查表、模板、对照表），放在最该用的那一节或文末「收藏这张表」；里面的分类、步骤、标准、数字都要来自料，主人没给就用主人现成的（档案里的福利）或只写表头标【问】，不替主人填。
- **结尾**：一个今天就能做的动作 ＋ 收尾引导（`钩子卡.md` 第五节：好回答的评论问题、收藏理由）；福利放文末，交付方式按平台写（禁导流的平台直接把福利做进正文或图里，不写「私信领取」）。
- **论点要有东西**：【论点】是从主人的做法里提炼的一句读者能照做的话（「孩子的东西，让孩子自己挑」「先装箱，一个月后再决定」），不是复述发生了什么——「这次先动的是玄关那个柜子」「我们先把书分成三类」是事实，标【证据】。料里提炼不出，就问主人一句「这件事你最想让读者记住哪句」（标【问】），或者这一节干脆不写论点，不硬写一句空的；但**全篇至少要有一句核心论点**（放开头四件套第③项或第一章开头，比如「起夜的路上，一样东西都别放」），其余小节可省。论点是说给读者的：不许讲怎么写稿（「先把哪句话最扎眼摆出来」），不许提「料」「材料」这类幕后的词（「这条料里已经给了……」）。长文第一句同口播钩子（`钩子卡.md` 第二节），不从「这周二我去了……」讲起，最扎眼的痛或前后对比放第一句。
- **写作稿的段落标注**（给主人审稿看，发布时去掉）：段首写 `【钩子】【论点】【证据】【槽点】【收藏件】` 标明这段干什么；图片位写 `👇【图】这张图看什么｜要拍：…｜没有就：…`（图表、视频把【图】换成【图表】【视频】）。能跑程序就用同目录 `长文排版.py` 转成网页：有「写作视图」（按颜色标出钩子、论点、证据、槽点、图片位）和「发布视图」（读者看到的样子）两种，再加一份去掉标注的发布版文字。
- **交稿样子**：
```
标题：…（候选 2 个）
约 N 分钟读完

【钩子】第一段……
【槽点】……
【论点】这篇给你……建议先收藏。
目录：1. … 2. … 3. …
```

## 二¼、小红书笔记（1000 字以内）
- 不用小标题，分段短；收藏件必须有一个（清单或做成图）；搜索词三处一致照平台卡。
- 节奏按长文的短版走（pen-angle 长文那套）：第一句带搜索词和钩子，每段一个点，收藏件放中段或末尾。主人要发「写长文」再按长文全套。

## 二½、X 帖子
- **单帖**：第一句就是钩子（数字、结果、冲突）；只讲一个点；清单、步骤最容易被收藏；末句留一个问题或邀请补充（评论比点赞值钱）。
- **帖子串**：第一条单独能看懂，说清整串给什么；后面每条一个点、一条料；最后一条收尾给动作或收藏件。跑检查用 `--form 长文`（帖子没有单独的口径，事实、数字、限定词照查）。
- **Article**：照长文写，标题宜短（平台卡）。
- 外链可以放；不写公众号式的「回复关键词」。外文素材用主人口吻重写，不照搬译文。

## 三、一料两版
同一份料出口播和长文：事实完全一致、都不编；交稿时说一句差别——口播短句、停顿、按秒算字数，长文有小标题和收藏件、按平台算篇幅。
