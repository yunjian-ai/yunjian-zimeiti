# 成品卡：问清一次，下一条就交成品

> 给人看：主人要的是能发的东西，不是过程。执笔问清楚要做什么（最多问一轮），下一条回复就交排好版、配好图的成品；中间的拆解、检查都在后台做，结果放进包里，主人想看再看。
> 给 AI：写稿、仿写、改稿的技能交东西都照这张；和技能里「交稿」一节冲突时，以这张为准。主人说「一步步来」「先给我骨架」「先看初稿」，才按技能原来的分步走。

## 1. 需求最多问一轮
- 开工只问**决定做什么**的那一个问题，给 2～4 个选项、第一项标「推荐」；作者档案里有的、从料里看得出的不问。
- 主人回「你定」「照你推荐的」「都行」：按推荐项走，不再问第二个。
- 只有缺了就没法写的，才在这一轮一起问（一次最多 3 个）：主人一条真事都没给、又要写主人自己的经历；带货缺价格、缺商品信息。别的缺口都不是停点（见第 3 节）。
- 这一问之后的下一条回复，就是第 2 节的成品。要做好几分钟的，先回一句「大概 N 分钟，好了发你」，不报过程。

## 2. 交什么
中间各步（清点料、定角度、搭骨架、写、深改、配图、平台版、自检）在一条回复里一口气做完，不停下来问「要不要接着深改」「要不要配图」。

| 形式 | 包里放 | 聊天里只放 |
|---|---|---|
| 长文、图文 | 定稿正文（排好版，`长文排版.py` 出的发布版网页＋能直接粘贴的文字）、封面、配图（每个图片位一张）、收藏件图、发布说明（每张图放在哪段后）、「自查记录」文件 | 一句话说交了什么＋标题；封面和一两张图的预览；要注意的事最多 3 条；「可以补的」最多 3 条 |
| 口播 | 提词卡（文字版＋`提词卡.py` 彩色网页）、封面文案和封面帧、「自查记录」文件 | 稿子本身（带色块段头、==重点==、**重读**）＋一行时长；要注意的最多 3 条 |
| 选题 | 3～5 个选题，每个一句为什么、配什么收藏件 | 选题本身，推荐 1 个 |

- **配图默认自己出**：按作者档案「配图」一项——「自己出」（默认）：环境能出图就出图卡；出不了就给每张图的提示词＋尺寸；「只给提示词」：只给提示词；「不要」：不配。规矩照 pen-cover。
- 能建文件就打成一个文件包交；不能建文件，就把成品整篇贴在聊天里，`自查记录` 放最后、标题写「自查记录（不用看）」。
- 平台：作者档案里第一个平台出发布版；主人点了平台就按主人的；别的平台版本主人要了再出（pen-platforms）。
- 聊天正文（不算稿子本身和预览图）不超过 8 行。

## 3. 【问】不是停点
- 缺主人本人的感受、经历、看法的地方：**删掉，前后接通顺**，成品照样交；不替主人编。
- 删掉的那几处里，最能让稿子更像主人的挑最多 3 条，放在聊天末尾：「想更像你，可以补这几句（不补也能发）：①…」。主人补了，改进去重交一版。
- 成品正文里不留【问】。【推算】照样写出算式，放进 「自查记录」文件，聊天里提一句请主人确认。
- 带货的价格、商品卖点缺了：照第 1 节先问，不交带空格的成品。

## 4. 检查照做，不展示
- 出处表（每句出自哪条料）、`check_pen.py`（硬错改到零、排版和说人话那几类清零）、仿写的原创度（和原稿连续 15 字以上相同 0 处）、违规词和导流、图上数字和正文一致——全照各技能原来的要求做，结果写进 「自查记录」文件，「机械检查」照抄脚本第一行和最后一行。
- 聊天里只写一行结果：「检查过了：事实都有出处、原创度、违规词都过」；有过不去的，说清哪一处。主人说「给我看出处」「看检查」，再贴出来。

## 5. 不说过程话
不说「我先拆一下结构」「我先看看规则」「对照原文」「重点不丢 ✅」「接下来我会……」；要讲的只有结果和要主人知道的事。

## 6. 交完
- 末尾不问「要不要接着……」；主人有改的地方会说。
- 主人说「哪里改一下」：只改那一处，重交受影响的文件，聊天里一句说改了什么。
- 演练模式下照常交，不写记忆。
