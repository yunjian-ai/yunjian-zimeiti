# 去AI味卡

> 卡类：口径｜改了要回归考题

> 给人看：AI 味的根子是姿态：站得比观众高、替观众想好问题、句句对却没一句是这个人才会说的。标准只有一个：主人念了说「这是我会说的话」。
> 给 AI：pen-polish、pen-check、pen-draft 用。命中的是动作不是字面；单个词只是线索，回上下文判断，没毛病的原样留。

目录：一、底线　二、七组看什么（含翻案腔外衣表）　三、放过和要保护的　四、三档怎么改　五、改完查什么　六、交什么

## 一、底线（冲突时按这个先后）
1. **事实和分寸不动**：不加主人没给的事实、数字、人物、经历、原话、归因、概括（`写法卡.md` 第三节那几种都算）；原文的信息一条不丢；谁做的、条件、范围、否定、完成状态不变；「可能」不改「一定」，「计划」不改「已经」，「有关」不改「因为」，「超过 3 千」不改「3 千」，「我觉得」不改「大家都知道」。
2. **只改主人要改的**：说「顺一顺」就不重写观点、不扩写、不换结构；要补料、扩写，新加的和原文分开标。
3. **像主人**：照口吻档案的句长、自称、口头禅频率、标点；保留清单最大，下面哪组都不能删它。替换时换成主人样稿里的说法，不往「标准好文」改；没有档案就保留原稿的说话方式。
4. **最后才改句式**：前三条守住了，再处理第二节。

## 二、七组看什么（编号供改动清单引用；必改 / 看情况）
**A 姿态**（根子，先看）
- A1 先立误解再推翻（外衣见下表）｜必改
- A2 说教、居高临下（你要明白、记住、你必须）｜必改
- A3 替主人下料里没有的判断：归因、概括、听来的问答、没依据的比较（`写法卡.md` 第三节）｜必改，删或标【问】
- A4 结尾往上拔：本质、人生、时代，比正文大几号｜必改
- A5 跟假想敌吵、自我辩护（不是我制造焦虑、不要误会）｜必改
- A6 全篇没有一处主人的犹豫、栽过的跟头｜看情况（主人给过就补，没给不编）

**翻案腔外衣表**（A1 按动作查，下面只是常见的几件）
| 外衣 | 例子 |
|---|---|
| 字面翻案 | 不是 A 而是 B；并非 A 而是 B；不在于 A 而在于 B |
| 省字、跨句 | 不是 A，是 B。／不是 A。而是 B。／问题不在 A，在 B |
| 以为体 | 你以为 A，其实 B；我一直以为 A，后来才发现 B；回头才发现 |
| 看似体 | 看似 A 实则 B；表面上 A，其实 B；大家都说 A，真相是 B |
| 抬价体 | A 不重要，重要的是 B；缺的从来不是 A；省的不只是 A，是 B；与其说 A 不如说 B |
拆法：找到这句原本想下的判断，正面说，依据放旁边。料里真有主人从误解到修正的经过，可以留一次，不套上面的句式。

**B 结构和节奏**
- B1 硬凑的三段、等长排比，每项没有独立内容；同一个开头连用三次｜看情况（留两项，第三项换说法或删）
- B2 每段一句金句收尾；单句碎片造悬念（「没了。全没了。」）｜看情况
- B3 句子一样长、段落一样长，像打拍子（照 `写法卡.md` 第六节数）｜必改
- B4 开头三件套（钩子、痛点、承诺），正文兑现不了｜必改
- B5 起跑式铺垫（今天跟大家聊聊、让我们来看看、以下是你需要知道的）｜必改
- B6 破折号当万能连接、冒号当提示（「核心是：」「一句话总结：」）｜看情况（引出原话、清单可留）

**C 用词**
- C1 路标词堆在散文里（首先其次、然而、值得注意的是、综上所述、总而言之、说白了、本质上、换句话说、不可否认、这意味着）｜看情况
- C2 动词压成名词（进行调整、实现增长、完成了对……的、起到……作用、具有……意义）｜必改
- C3 大词后面没有数字（赋能、闭环、底层逻辑、抓手、认知升级、降本增效、至关重要、全方位）｜必改
- C4 意义拔高的尾巴（彰显了、标志着、见证了、开启新篇章）｜必改
- C5 同一样东西换四个词说；抽象名词配具体动词装深沉（时间保管细节、焦虑显出形状）；拿仓库、温度、浪潮、地基、赛道包装抽象概念，几套比喻轮流来｜必改
- C6 限定词叠着（也许可能、或许大概）；生造标签后面还得解释｜看情况

**D 内容**
- D1 正确的废话：句句都对，观众明天什么也做不了｜必改
- D2 没名没姓没细节的故事（有个朋友、很多老板）｜必改
- D3 假精确：主人没给过的「3 秒」「47%」｜必改，标【问】
- D4 假具体：料里没有的时间、天气、神态、摆设、对白｜必改，删
- D5 借权威：「专家说」「研究表明」没出处｜必改（不补编的出处，删或标【问】）
- D6 画饼和承诺（你也能、轻松、躺赚、再也不……）｜必改

**E 量产感**
- E1 结尾空喊互动或送祝福（点赞收藏关注、我们下期见、愿你……）｜必改。带理由、带具体动作的引导（「想照这三格分的，先收藏」「评论区报个日期」）是钩子卡第五节要求的，不算
- E2 万能称呼（家人们、宝子们、亲们）、表情符号成串｜必改（主人自己常用的除外）
- E3 档案里没有的口头禅被塞进来、档案里的用得太密｜必改
- E4 客服腔（好问题！希望对你有帮助！）｜必改
- E5 标题党（震惊、绝了、一定要看完）｜看情况

**F 念出来**（口播专项）
- F1 一句超过 25 字不断开｜必改
- F2 只能看不能听：括号补充、斜杠并列、英文缩写、「如下图」｜必改
- F3 数字和单位不好念（3.5w+、1/3）｜看情况
- F4 代词找不到是谁、同音容易听岔、拗口连读｜看情况
- F5 书面腔（其、之、予以、该）｜必改

**G 中文语病**（AI 写中文的老毛病）
- G1 词序颠倒（零散写成散零）、字词错位｜必改
- G2 搭配不当、缺主语、主语中途换人｜必改
- G3 前后说法矛盾（前面 4 年、后面 5 年）｜必改，标【问】，不替主人挑一个
- G4 层叠的「的」、一串被字句、主干压到句尾（照 `写法卡.md` 第五节）｜看情况
- G5 「随着……的发展」「在……的背景下」开头，背景没有信息｜看情况

## 三、放过和要保护的
**放过**（不算毛病）
- 成团才算：一个破折号、一个「至关重要」、一组三项列举，人也这么写；同一段里几样一起出现才算。四十字以下的短句子不判节奏。
- 主人自己的口头禅、行业词、招牌说法，频率在档案范围内。
- 大词、排比后面紧跟真数字或真事；方法型稿子和小红书的编号步骤；表示先后的「首先」「第二步」。
- 有用的连接词（所以、但是）和该重复的词，不删。
- 主人亲口说过「真有人这么问」的误解（留一次）；主人有意的短句、排比；别人的原话。
- 第一节第 1 条要保的限定（可能、计划、超过、据说）。

**要保护的人味信号**（见到就别动）
- 编不出来的具体：真日期、真价格、真名字、量出来的数字（「10 分钟变 2 分钟」）。
- 拿不准、没想通、前后有点矛盾的真话（「我到现在也说不好值不值」）；主人自己的偏见和立场。
- 亲历才有的细节、只有干这行的人才会注意的地方。
- 故意的不完美：一个短句碎片、一次岔开再接回、一个说停就停的结尾。
已经活着的段落，最好的改法常常是不改。

## 四、三档怎么改
- **只扫不改**（pen-check 用）：标位置、组号、级别，不动稿子。
- **轻改**、**深改**：做法只写在 pen-polish 第 5 节（深改七步），这里不再抄一遍。

## 五、改完查什么
1. 跑 `check_pen.py`（会按组标出机器扫得到的线索：翻案腔、套话、名词化、句长、连词、比喻换场），回原文逐条判。跑不了就照第二节重扫，特别看新冒出来的金句和排比——重写的句子会带着同样的毛病回来。
2. 再问一轮「还有哪里读着像 AI」，列两三处改掉。只再改这一轮，改多了会改成一顿一顿、没有人味的短句。
3. 对出处：新出现的每个数字、每件事、每个判断都找得到料吗？找不到撤回。
4. 对分寸：原文的每条信息、每个限定都还在吗？保留清单的每一项都还在吗？
5. 冷读：忘掉规则念一遍——哪里让人相信主人真干过这件事？哪句话说得比料大？在哪一句其实已经讲完了？

## 六、交什么
```
档位：只扫 / 轻改 / 深改
问题清单：第 N 段「原句」｜组号（如 A1）｜必改 / 看情况
改后全文（只扫档不出）
改了哪几处：原句 → 新句｜组号
补进的主人的话（深改）：「…」出自样稿第 N 段 / 作者档案 / 本次对话
故意没改的：「…」｜放过的理由
核对：新增事实 无 ✓｜原文信息和限定 全在 ✓｜保留清单 全在 ✓｜句长：…｜事实问题：【问】…
```
