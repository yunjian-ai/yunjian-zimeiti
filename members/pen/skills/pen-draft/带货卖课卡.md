# 带货卖课卡

> 卡类：口径｜改了要回归考题

> 给人看：卖东西的稿子要让观众走完「停下来 → 想要 → 相信 → 现在就买」。每个手法都要主人给真材料，没有就不用，不编。
> 给 AI：种草带货、卖课稿型时 pen-title、pen-draft、pen-check 读这张，和 `规则卡.md` 第 1、8 条一起守。

## 一、结构
- **长文、详情、公众号**：标题 → 欲望 → 信任 → 欲望 → 信任 → 下单。欲望是感性的「想要」，信任是理性的「信得过」，两样交替叠两三轮，力度才够；只写一遍欲望就跳到信任，卖不动。
- **口播、直播**（五步成交，每步回答观众心里一个「为什么」）：留人（为什么停下来，人群点名＋场景）→ 价值（为什么要它，最长：痛点 → 卖点 → 证据 → 用上以后的样子）→ 比价（为什么在这买，真实价格和赠品）→ 保障（为什么放心，退换、试用、售后）→ 稀缺（为什么现在，真实名额或截止点）。一上来就报价是跳步。
- **卖课、发售**：干货（先给一个真能用的小结果）→ 案例（主人自己或授权学员的真事）→ 痛点（不学会怎样）→ 发售（课里有什么、怎么交付、多少钱）→ 促单（真实的截止和名额）。短口播可以用三句：「你是不是也……」→「其实只要……」→「我也是普通人……」，每句都要有料。
- **功能翻译**：功能 → 在什么场景下 → 观众能得到什么好处 → 避免什么痛苦。人群、场景、痛点、产品四样有一样说空，购买理由就站不住。

## 二、观众在哪一级（决定开头讲什么）
还不知道自己有问题 → 先讲场景和代价；知道问题 → 先讲为什么一直解决不了；知道有办法 → 讲为什么是这个办法；知道你的产品或课 → 讲证据和差别；已经想买 → 直接讲价格、赠品、截止。拿不准就按「知道问题」写。

## 三、手法、异议、合规替换（查表，在库里）
写之前查 `带货卖课.md`（执笔库「手法」）：11 个手法各要主人给什么料、什么时候别用；嫌贵、怕假、怕不适合、怕没效果、怕售后各怎么答；不能说的换成什么。读不到库：手法只用主人给了料的，异议主动替观众问一句再用主人的事实答，有风险的说法照 `规则卡.md` 第 8 条换。卖课再查价值：结果 × 相信能做到 ÷（要等多久 × 要付出多少），哪项弱请主人补那一项的真材料。口播里的卖点、参数、赠品要和商品页一致。

## 四、挑刺观众审稿（pen-check 用）
写完请三个人「看」一遍：嫌贵的、怕被骗的、觉得跟自己没关系的。每人问一句心里话（「凭什么这个价？」「你自己用过吗？」「这跟我有啥关系？」），稿子里找得到答案才算过；找不到，写进自检的 ❌ 或请主人补料。
