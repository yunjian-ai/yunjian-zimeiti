# 出稿

## 0. 开写前
- 读同目录的 `规则卡.md`、`成品卡.md`、`写法卡.md`、`形式卡.md`、`骨架卡.md`、`钩子卡.md`、`人话卡.md`，记忆里的「作者档案」「口吻档案」，以及 pen-angle 的输出：材料清单、钩子骨架、选定的开头、收藏件和福利、参照的爆款卡。没走过 pen-angle 的，先照它清点材料、过开头关、搭骨架（可以在同一条回复里做完）。
- **形式和长短**：平台和形式照 `形式卡.md` 第〇节定（pen-angle 定过就照用）。口播按主人给的时长算字数（第一节，60 秒 220～260 字），没给按档案和平台打法，都没有默认 60～90 秒。长文按料估：每条料约 120～150 字乘条数，复盘、方法 1500～2500 字，观点 1000～1500 字；开写前把预计篇幅告诉主人，主人另有要求按主人的。料少就写短，不注水。主人说「都要」照 `形式卡.md` 第三节出两版，同一条回复里交：先母版，再平台版。
- 这一步只写**母版**，不分平台；平台版本交给 pen-platforms。
- 没走 pen-angle、在同一条回复里清点和搭骨架的：材料清单、钩子链、出处表只在稿后写一份，不重复；**「说给谁」照样列两三个候选再挑**（pen-angle 第 2 节），不能只写一个。

## 1. 能用的料（只有这些）
- 作者档案里的真事素材库；
- 主人的样稿原文（口吻档案的证据片段）；
- 主人在这次对话里亲口说的话；
- 有出处的【推算】：算式写出来，主人点头才算数；
- 别人的公开案例：资源合集、主人让找、或稿子要外部例子而主人没料时，照 `案例卡.md` 找，写成别人的事、带出处。
**不能用**：学口吻时那段试写；别人身上的事；行里人常说的「一般来说」；为了把段落凑圆顺手补的动作、心情、小数字（几天、几次、几个人）；替主人下的归因、概括、听来的话（`写法卡.md` 第三节）。
- **只有一个选题、没有料**：不出整篇，照 `规则卡.md` 第 1 条问料（一次最多 3 个），可以附一个只有骨架、不带事实的提纲，标「提纲，等料」。还没有口吻档案的，同一条回复里请主人顺手给几段平时的口播或文章。
- **种草带货、主人给了产品和时长要成稿**（价格、商品卖点缺了，先在第一问里问齐，成品卡第 1 节；问了不答，才照下面写）：照时长出稿，**五步一步不落、字数按时长写够**，不能料少就只交半条，也不能停在那光问；缺料的那一步写成一句完整的话，只把缺的那个词换成【问】（「这场到手价是【问：多少钱？】，比日常价便宜在哪你一眼能看到」），整条念出来要到时长下限的 85% 以上（`check_pen.py` 不数【问】里的字）。商品信息主人没给，「商家说」后面只写【问：商品页写的卖点是什么？】，**不替商家编卖点**（材质、尺寸、功能都算）。产品好处写成「商家说……」或主人能确认的说法，主人实测的证据、学员结果的位置标【问：您实测……？】，稿后列出这几个问题。

## 2. 写法
1. 开头就用主人选定的那个，一字不改放上去。
2. 按钩子骨架逐段写：每段钩子 → 兑现（料＋手法）→ 引出下一个钩子（`钩子卡.md` 第四节）；每节三样：观点（一句）、材料（标出处）、观众能做的一个动作。口播每 10～15 秒一个新钩子。重点、爆点、槽点、知识点落在骨架标的位置。
3. 哪一节料少：就写一小段，只放说得出来源的；空着的地方先标 `【问：具体问题】`，交成品前照 `成品卡.md` 第 3 节删掉写通顺；骨架上整节标了「待问，未答不写」的，主人不答，**这节就空着不写**。
4. 句子照 `写法卡.md` 第五节：主干先出、连词少、同词不躲；不归因、不概括、不编听来的话、不先立误解再推翻。
5. 节奏跟口吻档案走：句子多长、段落多长、怎么自称、标点、口头禅多久一次放在哪。口播照 `形式卡.md` 第一节：按说话的停顿断行、加粗重音、一句不超过 25 字；句子顺着说（谁、干了什么、结果），不为了短把东西提到前面再加逗号。
6. 收藏件放在骨架规定的位置：**每一格都要有料号**，进出处表；不知道的格子留空或标【问】，不替主人编做法；执笔替主人归纳的清单，别说成主人一直在用；**怎么引出收藏件不固定**，跟着这条稿子的话头走（「记住三件事」「照这个顺序来」「截个图」「门背后贴一张」），不要每条都用「我把这次的做法整理成……」这一句（`check_pen.py` 的 TEMPLATE_LINE 会提醒）。
7. **正文只写给观众听的话**：给主人的说明、【问】的理由、出处，一律放在稿子外面。
8. 没有口吻档案时，句长和口头禅照主人原稿或口述的说话方式。
9. 福利放最后；怎么送先按母版写，各平台的不同交给 pen-platforms 处理。
10. 结尾落在一个动作、一个数字或主人的一句话上；口播结尾照 `钩子卡.md` 第五节给收尾引导（好回答的评论问题或说清理由的收藏），带货的行动放正文最后一句。口播开头先过 `钩子卡.md` 第二节的划走测试，骨架不按时间顺序讲。

## 3. 写完自查（交出去之前）
- **先念一遍（硬性，每条都做，不许跳）**：每段从头念到尾，照 `人话卡.md` 第零节对六样，哪段卡壳、接不上、倒装，改了再往下：①**人称**：「我」只是主人，「你」只是正在看的那个观众（不用「您」「大家」），「她／他」只是客户；②**顺着说**：谁、干了什么、结果，没有把东西提到前面再加逗号（✗「常用的两根充电线，放最上面」）；③**口头禅**只在一句话开头、后面是要强调的话，不夹在半句中间（✗「走的时候，说真的，……」），不放在交代时长、经过的句子前；④**转述**说全主语（「她说她打算……」）或用冒号学她说（「她说：……」），不写「她说，打算……」；⑤**前后句接得上**，像讲一件事，不像念清单；⑥**不拗口**：念着绕嘴的说法换掉，料里的原话也一样（✗「洗手台露出了大半个台面」，洗手台露出它自己的台面），意思不变。再对一遍 `人话卡.md` 第四节的范文。像在念文件的句子改成说出来的话（口播用口述形式，长文也说人话）；样稿里的观点句不往不相干的稿子里塞。
- **逐句**过：每句后面抄出料里的原话（「料原话「…」」），或者写「连接，不带事实」（连接句里不许有动作、数量、原因、状态）。抄不出原话的就删，或改成【问】。`check_pen.py` 会核对抄的原话在料里搜不搜得到。
- 能跑程序就运行 `check_pen.py`（同目录），口播加 `--seconds`，有料加 `--material`，知道平台加 `--platform`，带货加 `--ad`；不想建文件，稿子写 `-` 从标准输入给：`python3 check_pen.py - --material <料文件> --form 口播 --seconds 60`。❌ 硬错改到零，⚠️ 提醒逐条回原文判断；**排版和开头这几类提醒一律改到清零**：COLOR_MISSING、CUE_MISSING、HIGHLIGHT_MISSING、BOLD_MISSING、OLD_HEADER、HOOK_INVERT、TOC_MISSING、SUBSECTION_MISSING、SYMBOL_MISSING；**说人话这几类也改到清零**：FILLER_MID（口头禅夹半句）、FILLER_NUMBER（口头禅放在报数交代前）、QUOTE_SUBJECT（转述丢主语）、PERSON_WORD（对观众用「您」「大家」）、SELF_OBJECT（自己露出自己）；HABIT（「一开就是」把一次说成每次）回料里看，料里只有一次的改回原话；FRONT_OBJ（把东西提到前面）逐处念一遍，倒装的改成顺着说。交稿写的字数和句长用它数的，**「机械检查」那一行原样抄脚本输出的第一行**（「约 N 字，预计 M 秒｜检查码 xxxxxx」）和最后一行结论，不自己写数。**顺序写死：正文定稿 → 跑脚本 → 抄第一行；抄完正文一个字都不再动，要动就整篇重跑再抄**（检查码由正文算出，改一个字码就变，判的人一算就知道）；真跑不了就逐行手数，写「手数，没跑脚本」，不许写「检查通过」。
- 非带货稿料只够写短（只在够不上 `写法卡.md` 第二节门槛时；够门槛就写满时长）：跑检查时不加 `--seconds`（不然报字数硬错），交稿写「料只够约 N 秒」。长文写不满也照发，并给一句建议：几百字的公众号照样能发，也可以改发小红书笔记或 X 帖子串。
- 篇幅和目标差多少？长文超出 30% 先删重复的例子；口播超出范围先删重复的那句；不够也不补，直接说「料只够这么长」。
- 收藏件和福利都放了没有？骨架上的每一节都写到了没有？没写的那节注明为什么（待问）。

## 4. 交稿
**默认照 `成品卡.md` 交成品**：写完接着照 pen-polish 深改、照 pen-cover 配图，在同一条回复里交成品包；聊天里只放成品卡第 2 节那几样。下面这份写进包里的 「自查记录」文件（主人说「一步步来」「先看初稿」时才贴进聊天）：
```
母版｜口播 N 秒 或 长文｜计划 N 字｜写出约 M 字
标题：…
正文…（口播按 `形式卡.md` 第一节的交稿样子：分段、段头带〔提示〕、==重点== 和 **重读**；**聊天里交的文字版本身就带色块段头、==重点== 和 **重读**——提词卡网页只是另一种看法，不替代**；能跑程序就再用同目录 `提词卡.py` 转成彩色提词卡一起交，跑不了就只交文字版）；长文按第二节的写作稿样子（段首【钩子】【论点】【证据】【槽点】【收藏件】、👇【图】图片位、★ 💡 ⚠️），**聊天里交的是这份写作稿（带段落标注、目录、两级编号）**，能跑程序就用 `长文排版.py` 转成网页（写作视图／发布视图）并附发布版文字
出处表（跟稿子一起交给检查脚本；口播逐句，长文可以逐节、每节列出用到的料原话）：第 1 句 → 料原话「…」（素材第 N 条 / 样稿第 N 段 / 本次对话）/ 连接，不带事实 / 处境问句 / 给观众的动作或问题（只许这四种，写法卡第三节）；收藏件每格同样列
钩子链：①…｜重点：…｜爆点：…｜槽点：…｜知识点：…（`钩子卡.md` 第四节的样子）
执笔补的说明：…（只讲工具、原理的一般说法，请主人确认；没有就不写这行）
借用单：段落位置｜借的哪招（公式）｜卡 id｜稿里哪一句；没用上库写「没用上库：原因」（pen-library 第 2 节；检查时加 `--cards`）
参照：爆款卡 id …（借了什么）/ 没用上库
句长：…｜推进节点（口播）：0～3 秒 …、3～10 秒 …
待问：【问】…（N 处）｜推算：【推算】…
跳过的节：…（原因）
```
口吻档案是草稿版的，这次对话交第一份稿时提醒一次「档案还是草稿版，再给几段样稿会更像」。成品里不留【问】：缺主人感受、经历的地方删掉写通顺，最多 3 条放进「可以补的」（成品卡第 3 节）；只有成品卡第 1 节那几种缺了就没法写的才先问。主人说「一步步来」「只要初稿」：交初稿和上面这份，问一句「要不要接着深改」就停。演练模式下照常出稿，不写记忆。

## 意外
- 主人给的料自相矛盾（前面 4 年、后面 5 年）：两个都不用，标【问】。
- 内容涉及功效、收益承诺或极限词：照 `规则卡.md` 第 8 条。
- 主人催「别问了直接写」：照写，缺料的地方删掉写通顺，不补编。

## 不做
找选题、抓数据；配图和画面方案（交给 pen-cover）、拍剪出片；替主人发布；编主人的经历和数字。
