# 骨架卡：五类稿型

> 卡类：口径｜改了要回归考题

> 给人看：稿子按讲的是什么事分五类，各有顺序；口播和长文通用，长文把每一步展开成一节。
> 给 AI：pen-title、pen-draft 用；判不准选料最多的那类，说一句为什么。

| 稿型 | 认法 | 顺序 |
|---|---|---|
| 复盘（最值钱，先考虑它） | 主人亲手办过一件事，前后有变化 | 怎么起的头（具体场景）→ 头一回怎么干的、哪里错了 → 改成了什么做法 → 结果和数字 → 观众照着做的几步 → 收藏件 |
| 方法（次优先） | 主人要教一套做法 | 要解决的问题（观众此刻卡在哪）→ 步骤一二三，每步配一件真事作证 → 常见的坑 → 收藏件 |
| 观点 | 主人对某个现象有自己的看法 | 一个观众亲眼见过的现象 → 一般人怎么看、所以怎么做 → 这种看法为什么吃得开 → 主人的看法（得跟前面真对着干，不是换个说法；也不替观众编一个误解）→ 具体怎么改 → 再往大一点的道理上放（想不透就别写，不硬往高处拔） |
| 种草带货、卖课 | 推一样产品或一门课 | 照 `带货卖课卡.md` 第一节：长文欲望和信任交替叠两三轮，口播走五步成交，卖课走发售循环；证据只用主人实测、真评价、学员真结果 |
| 资源合集 | 整理一批工具、书、模板、课 | 为什么整理 → 逐条（每条一句用法＋主人自己的使用情况）→ 怎么挑 |

## 口播不按时间讲
上表的顺序是长文和讲清楚用的。写成口播（尤其 60 秒以内），**先亮最扎眼的冲突或结果，再倒回去讲**：钩子 → 冲突 → 戳观众 → 转折 → 结果 → 收尾引导（`钩子卡.md` 第四、五节）。「那天去了谁家 → 看到什么 → 做了什么 → 客户说了什么」照时间排，就是流水账。

## 变化
- 同一类里可以换讲法：先说结果再倒回去讲、对比（以前 vs 现在）、清单（三个……）、一问一答、讲一个人的故事。选哪种看料：有前后数字用对比，有好几步用清单，有一个具体客户用故事。
- 讲人的时候写具体场景和细节（几平米、几件、几点），不写「很乱」「很多」。

## 料够不够
- 复盘、方法：至少一件主人做过的真事，带一个具体数字或场景；没有就先问。
- 观点：至少一个主人亲眼见过的例子撑住「为什么」。
- 种草带货：至少一样主人自己用过的证据；只有厂家说法时，写成「商家说……」，不当成主人的话；卖课的学员结果照 `带货卖课.md`（库）。
- 资源合集：每条都要有主人自己用过的一句话，没用过的不放进去。

## 每节都要有
一个观点、一条真材料、观众今天就能做的一个动作。案例从弱到强排，最有分量的放后面。只是猎奇、没有方法的选题，往复盘或方法上靠。
