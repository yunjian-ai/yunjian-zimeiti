# 选题与标题

## 1. 动手前看作者档案和口吻档案
读 pen-draft 的 `规则卡.md`、`钩子卡.md`、`形式卡.md`、`平台卡.md`，库 `平台/<平台>/规则.md`，和记忆里的「作者档案」「口吻档案」。没有作者档案就先照 pen-getting-started 问。档案「还没问的题」里还有人设、立场、号上爆过的，写第二篇起每回先插问一题（pen-getting-started 第 6 步），再出选题。

## 1½. 先定平台和形式
照 `形式卡.md` 第〇节：先问发到哪，再看库里这个平台爆得多的是口播、长文还是帖子，照这个推荐并讲出依据，主人可以改。库读不到就按默认表，并告诉主人这次没用上库。

## 2. 选题
- **只写发生过的事：** 每个选题对应素材库里的一条，写上是第几条。标了「不公开」的跳过，「禁写」里沾边的一律不碰。
- 主人想写的事素材库里没有：先问清楚，记进素材库，再出题。热点最多拿来开个头，撑起正文的还得是主人自己的事。
- **三把尺：** 看了标题想点开（好奇）、看完想收着（手里多了能用的东西）、想转给别人（说中了某一类人）。三把里至少占两把，其中「想收着」非占不可。口播多一把「想看完」：料够不够串成一条一问接一问的链，见 `写法卡.md` 第八节。
- **收藏件：** 每个选题说清带什么：对照表、清单、模板、计算表、流程图或话术单，格子要能用主人的真事填满；填不满就拿主人手上现成的（档案里的福利、主人正在用的表），分类和步骤不替主人定。标题写「附 N 个」，N 只算主人真给出来的。
- **文末福利：** 档案里有福利就带上；档案写的「还没有」，就把这篇的收藏件扩一扩当福利。
- 每次出 3 个选题；素材不够 3 件，有几件出几个，不凑。每个选题列出：用的素材条目、平台和形式、收藏件、占了哪几把尺。

## 3. 标题
选题定了以后，先照 pen-library 第 2 节读目录、取 `招式/标题.md` 里的招，从库里抽 3～5 张同平台、同稿型的爆款卡，看它们的标题属于下面哪种、有多长（学写法，句子和数字不拿）；库读不到就直接照下面来。出 **5 个标题**，五种写法里至少用三种：
1. **身份＋大数字＋看得见的结果：** 身份越具体越好（「讲了 8 年课的人」强过「讲师」），数字要大也要准，结果是能看到的变化。
2. **干货承诺：** 保姆级、附 N 个模板、全部公开这类。N 就是正文里实打实给出的个数。
3. **冲突对照：** 两种做法对着放，或新手对老手，或「别人都说 A，我偏做 B」。
4. **反常识＋证据：** 结论让人意外，主人的数字直接放进标题当证据。
5. **悬念**（口播标题和封面字常用）：留一个问题不说破，但答案料里确实有。
带货卖课稿的标题不用「最」「竟然」这类词，不傍主人没合作过的名人名企（`带货卖课卡.md` 第五节）。
**容易没人看的写法不出：** 光发观点、光吐槽、骂人或骂一类人、只有情绪拿不出数字和做法。主人非要发吐槽，就改成对照型、补上一个真数字，并跟主人讲为什么。
每个标题后面注明用的哪种写法、冲着哪类观众。最后**推荐 1 个**，一句话说理由（数字最硬、收藏件最直观，或最戳观众的痛处）。

## 4. 数字的规矩（最重要）
- 标题里出现的数字，素材库里都得找得到原文。
- 自己算出来的数（「每天 200」算成「每月 6000」）标「推算」，先问主人能不能用。
- 主人给的是约数（「八万多」），标题照样写约数，或写「8 万+」；写成「8.3 万」就是编。
- 缺了数字就问，不编：写成 `【问：第一年亏了多少？】`。
- 身份数字（年限、学员数、店数）也要有出处，可以来自素材库，也可以来自口吻样稿（写明「样稿第 N 段」），顺口问一句要不要补进素材库。
- 不偷换说法：「第一年」和「第一家店」是两回事，「回本」和「赚了」不一样，「报名」也不等于「付费」。意思一变就标出来问。
- 动作、心情、细节同样不编：主人没说过「我才敢签合同」，标题里就没有这句。
- 收藏件是这次替主人整理的，标题写「附一张…表」；只有主人真的用过很多年，才写「附我用了多年的…表」。

## 5. 各平台版本
作者档案里选了哪些平台就出哪些，一个平台一行，写上实际字数和上限。抖音、视频号这类短视频没有文章标题，要出的是作品描述（大约 55 字之后会被折起来），照 `平台卡.md` 第二节。超了上限可以换更短的同义词，数字和结果不能动。上限和怎么数照 `平台卡.md`：小红书英文、数字各算半个字（例：「讲课8年，学员从40到800」＝中文和标点 9 个，加数字 6 个×0.5，共 12 字）；别的平台数字、标点、英文一律按 1 个字算，宁可数多。
- 缩短先砍修饰词，保住数字和结果。
- 禁导流平台的标题不出现「公众号」「加微信」「私信领取」，不放链接。
- 素材里没有的比例和百分比（「少花一半」「涨了 80%」）不写进标题，想用先问。
- 平台卡里没有的平台，先查它当前的标题上限再写；查不到给一个保守的短版本，并告诉主人上限没查到。

## 6. 交什么
```
平台和形式：…（依据：库 / 默认表）
选题：…（素材第 N 条｜收藏件：…｜占的尺：点 / 存 / 转 / 看完）
参照的爆款标题：卡 id …（写法）/ 没用上库
标题候选：
1. …（写法｜观众）
…
推荐：第 X 个，因为…
各平台：抖音（N 字 / 上限 M）… / 公众号（N 字 / 上限 M）…
待确认：【推算】… 【问】…
```
有待确认项时先问完，再交给 pen-angle 搭骨架、写开头。演练模式下照常交，不写记忆。

## 不做
去外面追热点、抓数据（参照爆款只从库里抽，找新爆款收进库用 pen-library）；编主人的数字和身份；替主人决定发哪个（推荐，由主人选）。
