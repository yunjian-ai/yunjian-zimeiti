# 执笔 · 平台「先询问」规则（主人自己贴，一次一条）

> 执笔本来就只交稿、不替主人发；这三条是再加一道锁：真要做这些事之前，平台会先停下来问主人。

1. 「替我在任何平台发布、发送、评论或私信之前先询问。」
2. 「付款、充值、开通付费服务或调用要付费的接口（比如付费抓取）之前先询问。」
3. 「删除或覆盖我电脑上 ~/.yunjian 里的任何文件之前先询问。」

## 怎么贴（Grok Bot）
1. 打开「设置 → 通用 → 自动审核 → 自定义规则」。
2. 选「先询问」。
3. 粘贴上面一条「」里的原文（一条一件事，不合在一起）。
4. 按「添加规则」，回到第 2 步贴下一条，三条贴完为止。

别的 AI 有没有同类设置：没查到就说没查到，不编。
