# 钩子骨架与开头

## 0. 开工前
读 pen-draft 的 `规则卡.md`、`写法卡.md`、`骨架卡.md`、`钩子卡.md`、`形式卡.md`，库 `平台/<平台>/规则.md`，和记忆里的「作者档案」「口吻档案」，以及 pen-title 的输出（平台和形式、选题、标题、待确认）。主人直接问「这个题从哪讲」、标题还没定的，先照 pen-title 第 3 节出 3 个标题（三种写法各一）推荐 1 个，再往下搭骨架；档案里没写的项（福利、平台）不说「档案里写了……」。

## 1. 清点材料（先做，不跳过）
- 把素材库、口吻样稿和这次聊天里跟标题有关的真东西一条一条摆出来：经历过的事、数字、说过的原话、动过的手、栽过的跟头、付出的代价、最后怎样了。每条后面写来源（素材第 N 条 / 样稿第 N 段 / 本次对话）。
- 门槛照 `写法卡.md` 第二节：长文至少 5 条，能连成一个过程，不能是 5 句同类的道理；口播每 30 秒至少两件。
- 料不够就一次问齐，不超过 3 问，专问能把正文撑起来的细节：到底怎么做的、当时是多少、半路出了什么岔子。主人答不出，就劝写短一点或换个题，不往里灌水。
- pen-title 留下的「待确认」先问清楚再动笔。

## 2. 开头关：观众能带走什么
动笔写开头前，先拿一句话回答：观众看完能拿走什么——一个判断、一个照着就能做的动作，或者一张拿去就能用的表。这句话写不出，就别往下，回第 1 步补料或换个切口。开头再漂亮，正文兑现不了，等于没写。

再定**说给谁**：同一件事换个听的人，戳的地方就不一样。列两三个候选再挑——比如「独居阿姨厨房里过期的调料」，说给收纳新手是方法，说给在外地工作的子女就是「你上次回家打开过爸妈的厨房吗」。挑那个最能让人停下来、转给别人的，交稿时写一句为什么。这一步库帮不上（库里的招只管位置），别拿借来的招代替角度。

## 3. 定稿型和钩子骨架
按 `骨架卡.md` 定这篇属于哪种稿型（复盘、方法、观点、种草带货、资源合集），讲一句理由；种草带货、卖课再读 `带货卖课卡.md`，先定观众在哪一级（第二节）、选哪几个手法（第三节，主人给不出料的手法不用）；只是猎奇、没有方法的选题，往复盘或方法上靠。
- 每一节（口播就是每一段）三样不能缺：一个看法、一条真料、一个观众当天就能动手的事。哪节得等主人回答才写得了，标「待问，未答不写」。
- 案例从弱到强排，最有分量的放后面。
- **参照爆款**：照 pen-library 第 2 节抽 3～5 张同平台同稿型的卡，看它们「钩子链」一节：钩子放在哪、隔多久一个、爆点在第几段、槽点怎么引。照**位置和节奏**搭，每一步换成主人的料；读不到库就照 `钩子卡.md` 第四节的通用样子。主人随料贴来卡、说「写一条」，算参照（只借位置和节奏）；说「照这条改」「仿写这条」，才走 pen-remake。
- **钩子链**（`钩子卡.md` 第四节）：每段写「钩子（类型）→ 兑现（料几＋手法）→ 引出下一个」；钩子接不住的不用。标出重点、爆点（至少一个）、槽点（真问题，不编争议）、知识点。
- **口播**：钩子链就是问题链（观众的疑问 → 这一句的回答 → 由此冒出的新问题），每 10～15 秒一个新钩子（`写法卡.md` 第八节）。
- **长文**：每个小标题本身是钩子，中段放收藏件；各平台怎么压缩交给 pen-platforms。
- **帖子串**：头一条把全串的钩子亮出来，之后一条讲一个点，最后一句把人引到下一条。

## 4. 收藏件和文末福利
- 收藏件起码一个（对照表、清单、计算表、流程图、模板、话术单都行），写明放第几节；口播写明在哪句里提到。
- 收藏件里的分类、步骤、标准和数字，样样得出自料。主人没给的，拿主人手上现成的（档案里的福利、正在用的表）顶上，或者只画表头、空格写【问】，别替主人填满。
- 文末福利：档案里有就用档案的；档案「还没问的题」里还有文末福利、入口关键词的，这时先问一句（pen-getting-started 第 6 步）；主人说没有，就把收藏件做成拿来能用的完整版，当福利送。
- **福利交到观众手上的方式看平台**（照 `平台卡.md`）：公众号能写「回复关键词领取」；抖音、视频号、小红书、微博就把福利整个放进正文或图里，「私信领取」「加微信」「去某平台搜」一概不写。
- 入口关键词只用在准许的平台，放在开头几段；不准的平台一个字也不提。档案里写了「不用」就不放，顶多提一句可以开。

## 5. 写开头
照 `钩子卡.md` 在料里翻五样东西（硬数字、转折、立场句、资格、处境），把原话摘下来；凑够 3 样才动笔，不够就回第 1 步接着问。
用三种办法一共出 3～5 个开头，每个都写明用上了哪几样、摘自哪条：
- **直接挖**：拿摘下来的原话换个顺序排，不添一件新事实。
- **补进来**：五样里缺的那样向主人要，主人给了才写这种，不给就不出。
- **藏答案**：原来的开头一上来就把结论交代了，改成先抛个问题或反差，答案挪到正文里。
每个开头先过**划走测试**（`钩子卡.md` 第二节：带冲突、反常、数字反差、悬念、给观众的好处至少一样，写明是哪种；光描述现场不算），再过五条检查：
1. 不看标题也能懂在讲什么、和观众有没有关系；
2. 第一句不用行话、不自我介绍、不用「你能……吗」这种质问；口播第一秒就有具体东西；
3. 开头许诺的东西，正文给得出来；
4. 不照搬同行的开头句式；
5. 符合口吻档案：口头禅频率、招牌句位置、标点习惯。
最后推荐 1 个，说清为什么。小红书正文第一句要包含标题里观众会去搜的那个词。

## 6. 交什么
```
材料清单：N 条（出处）｜待问：…
观众带走：…
说给谁：候选 A …／B …（／C …），选 …（为什么）
平台和形式：…｜稿型：…｜参照：爆款卡 id …（为什么像）/ 没用上库：原因
借用单：段落位置｜借的哪招（公式）｜卡 id｜稿里哪一句（pen-library 第 2 节）
钩子链：①0～3 秒｜钩：…（类型）｜兑现：…（料几，手法）｜引出：… ②…
每节：观点 / 材料 / 动作
重点：…｜爆点：…（第几段）｜槽点：…｜知识点：…
收藏件：…（放第 N 节）｜文末福利：…（每个平台怎么送到）
开头候选：A…（用上：数字 / 转折…，出自料几）B… C…
推荐：…，理由…
```
骨架和开头主人点了头，再交 pen-draft 写全文。演练时照样交，记忆不写。

## 意外
- 料和选题对不上（选题讲省钱，料讲做菜）：说出来，给一个能接上的讲法。
- 主人要「爆款角度」但料很平：照实说哪样料最能抓人，不靠夸大拔高。

## 不做
找选题、抓热点数据；写整篇（交给 pen-draft）；编料。
