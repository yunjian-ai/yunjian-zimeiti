# 多平台改写

平台的硬规格、编辑器的坑、导流禁用词在 pen-draft 的 `平台卡.md`；这个平台什么形式爆、多长、开头结尾怎么做、算法看重什么，在库 `平台/<平台>/规则.md`。动手前两份都读；读不到库就照平台卡和这一节的原则改，说一句没用上平台打法库。

## 1. 准备
- 读 pen-draft 的 `规则卡.md`、`形式卡.md`、`钩子卡.md`、`平台卡.md`、`人话卡.md`、`去AI味卡.md`，库 `平台/<平台>/规则.md`，和记忆里的「作者档案」「口吻档案」。
- **形式跟着平台换**（`形式卡.md` 第〇节）：母版是口播、要出公众号，就改写成长文；母版是长文、要出抖音，就改写成口播；出 X 就写成单帖或帖子串。换形式时钩子链跟着重搭，事实不动。
- 只改作者档案里选了的平台；主人点名的就出那几个。
- 母版里留着没解决的【问】【推算】，先找主人问掉；主人说「先空着」，或者没回话就直接要平台版，就把那句整句拿掉，标记也不留，稿后注明拿掉了哪句。**带货稿例外**：五步里缺的是价格、赠品、售后、截止这类商品信息，删了就卖不成，不整句拿掉——平台版照留【问】，交稿第一行写「带货稿还有 N 处没答，答完才能发」。
- 母版拿 pen-polish 改完的定稿；主人已经在哪个平台发了，就拿发出去的那版当母版。
- 主人要新加平台：先查清它眼下的规矩，照 `平台卡.md` 第五节补一张规格，查不到的项写「查不到」、取保守的数，然后再改。

## 2. 一个平台一个写法，不能照抄
主人的用词、数字、事实一律原样：为了压篇幅可以删，但不添新事实、新解释、新判断。能动的只有五处：
1. **标题**：不超字数，数字和结果留着，修饰词先砍；字数照 `平台卡.md` 第四节数，宁可数多。
2. **开头**：照这个平台的观众把头两三句重写（口播就是头 3 秒）。公众号得让人点开就往下读；小红书头一句带上搜索词；视频号可以先讲明「我是谁、凭啥说这个」。
3. **篇幅**：超了就压。先拿掉重复的例子和过渡段，数字、动作、收藏件留下。压的时候事实不变，主人的话不能压成别的意思。约数照原话写（「七八个」别写成「7 个」）。口播换平台，字数照同一个语速算：想念慢点就少写几个字，换算办法不变。
4. **福利交付**：公众号可以写「回复 XX 领取」（档案里选了用入口关键词才写），档案选了不用就把福利直接放正文；X、知乎放不放链接看各自规则；抖音、视频号、小红书、微博把福利整个放进正文，做成图或成段列出来，「私信 / 加微信 / 去某平台搜」都不写。
5. **结尾**：顺着平台的互动习惯小改，不喊「点赞收藏关注」。

## 3. 小红书另外要做的
- 从标题里挑一个观众会拿去搜的词，标题、正文头一句、第一个标签里都放它，三处用同一个词。搜索词放不进事实句，就放进问句或标题，料里的原词不改。
- 头一句可以拿搜索词发问（「课卖不动怎么办？」），但问完同一句里马上跟一个真事实，不光问不答。
- 标签 3～5 个，打头的就是这个搜索词。
- 普通笔记不超过 1000 字：开头、最要紧的几步做法、收藏件留下；别的放进图里或者删。
- 清单可以用数字编号排；表情符号偶尔用来分段，别一串串堆。

## 4. 禁导流平台清扫（抖音、视频号、小红书、微博、抖音长文，还有知乎里导流的那部分）
- 拿 `平台卡.md` 第三节的禁用词挨个搜一遍：网址和短链、二维码、「扫码」、公众号、微信、私信、主页、「评论区留」「去 X 搜」等等
- 搜到就改：「去 X 搜」改成把东西直接写进正文；「关注公众号领取」改成「表格就在下面」。
- 收藏件、图片上的字也要查（水印、二维码、网址）。

## 5. 每个平台都过一遍夸大说法
- 许诺挣钱、说功效、拿价格作证、用极限词：照 `规则卡.md` 第 8 条和库里 `带货卖课.md` 的替换表改，给出拿来就能用的说法；拿不出真凭据的直接删。

## 6. 交的是文字，发布不归执笔
- 一个平台交一份，包括：标题（写上字数和上限）、摘要或导语（这个平台有才写）、正文（口播就是整篇口播稿）、发布描述（短视频平台才有）、封面上那半句话、建议的话题或标签。
- 封面上的字从标题里挑最狠的半句（通常是数字加结果），和正文的数字一字不差，约数照写原话；图怎么做交给主人或别的工具。
- 永远不点「发布 / 发表 / 群发 / 发送」；发微博时请主人看一眼「仅粉丝阅读全文」开没开。

## 7. 交什么（一个平台一块）
```
【平台】标题（N 字，上限 M）
摘要 / 导语 / 发布描述：…（N 字，上限 M）
正文：…
福利怎么送：…｜封面半句：…｜标签或话题：…
清扫：禁用词 N 处已改｜夸大说法 N 处已改
主人发布前要做：加话题 / 核对数字 / …
```
交稿末尾附一张对照表，列出每个平台版本和母版不同的地方（标题、开头、篇幅、福利、结尾）。改完说一句「接着发前自检」，交给 pen-check。演练模式下照常交，不写记忆。

## 不做
不替主人发布；不批量自动发；不编新内容来凑平台差异；不做图。
