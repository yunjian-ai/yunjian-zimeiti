# 执笔 · 抓取工具使用说明

> 给人看：丢一条链接，把公开内容抓回来：正文或逐字稿、作者、时间、点赞评论转发收藏、图片、评论。免费方法优先，不登录、不用你的账号；免费拿不到的几项，可以用你自己开的付费接口 BeatAPI 补。技能说明在 `pen-fetch`。
> 给 AI：这里的代码来自 BeatAPI 开源的 omniscraper（MIT 许可，见同目录 `LICENSE`，来源版本见 `来源版本.txt`），执笔原样收进来用。改代码前先读 `README.md` 和 `docs/verification-2026-10-20.md`。

## 一、安装（Python 3.10 以上）
```
cd 抓取
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```
- 系统自带的 Python 太旧（比如 macOS 的 3.9）就换一个 3.10 以上的来建环境。
- **要逐字稿**再装两样，都装在这个环境里，不用 Homebrew、不动系统：
```
.venv/bin/pip install imageio-ffmpeg faster-whisper numpy
ln -sf "$(.venv/bin/python -c 'import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())')" .venv/bin/ffmpeg
```
  跑的时候把 `.venv/bin` 放到 PATH 前面（`PATH="$PWD/.venv/bin:$PATH" .venv/bin/python scrape.py …`），工具才找得到 ffmpeg。第一次转文字会下载语音模型（tiny 约 75MB）。

## 二、用法
```
.venv/bin/python scrape.py "<链接>" --out <文件夹>
  --with-comments     顺带抓评论（多数平台要付费接口）
  --with-media        下载图片、视频、音频
  --transcribe        转逐字稿（要 --with-media，要装好 ffmpeg 和 faster-whisper）
  --max-mb 20         限制下载大小，先小后大
  --fallback-tikhub   免费拿不到的项用 TikHub 补（环境变量 TIKHUB_API_KEY，主人同意这次花钱）；--fallback-beatapi 同理用 BeatAPI
```
每次生成 content.md（能读的正文）和 meta.json（全部数据：platform、title、author、published、text、stats、images、videos、comments、methods、needs_beatapi）。退出码 0 只说明正文抓到了，不代表每个字段都有；看 `methods` 日志和 `needs_beatapi`。

## 三、实测（2026-10-23，开发电脑，家用网络，全部免费、不登录）
| 平台 | 正文、作者、时间 | 互动数 | 评论内容 | 走的路 |
|---|---|---|---|---|
| 抖音 | ✅ | ✅ 点赞、评论数、转发、收藏 | 要付费 | 访客身份打开手机版分享页 |
| X | ✅ | ✅ 点赞、回复（转发数没出） | 要付费 | 推文嵌入接口 |
| 公众号 | ✅（正文夹少量乱码行，要清掉） | ❌ 阅读、点赞不公开 | 要付费 | 读文章网页正文 |
| 小红书 | 访客身份能建，首页推荐返回空 | — | — | 执笔暂不主攻小红书 |
| 逐字稿 | ✅ 链路通：抖音视频→音频→文字，免费（10-23 用 uv 装 imageio-ffmpeg、faster-whisper；pip 下载卡住时改用 uv） | | | 测试视频只有 8 秒且是唱歌，tiny 模型转出一句不准的**繁体**；口播要换 small/medium 模型并转简体，找一条真口播再测 |

其他平台（B站、YouTube、TikTok、Instagram、Facebook、Threads、LinkedIn、Reddit、Pinterest、Telegram、Medium、Substack、Bluesky）代码里都有，没在本机逐个测；原作者在云端机房测过的能力表见 `README.md` 和 `docs/`。

## 四、我们用的三个平台，免费怎么抓（先后顺序）
- **抖音**：①向字节的访客接口注册一个临时身份 → 用安卓手机的浏览器标识打开 `iesdouyin.com/share/video/<作品号>/`，从页面数据里取正文、统计、封面、图集、播放地址（把 `playwm` 换成 `play` 是无水印 720p）；②不行就用搜索引擎爬虫的标识打开 `douyin.com/video/<作品号>`，页面描述里有标题、作者、日期、点赞和评论数。评论、搜索、主页列表要签名，会被风控拦，只能走付费。
- **公众号**：直接读文章网页，正文在 `#js_content`，标题、作者、时间、图片都在页面里。阅读数、点赞数不公开，要付费。
- **X**：单条帖子走公开的嵌入接口，拿正文、点赞、回复、图片和视频；主页最近约 100 条走公开时间线页。评论和搜索要付费。
- 云端机房的网络会被多拦一些（B站、Reddit、YouTube 字幕等）；家用网络能解开大半，**先换网络，再考虑花钱**。

## 五、付费接口 BeatAPI（主人自己开）
- 注册 https://beatapi.io/sign-up → 控制台建密钥 https://beatapi.io/dashboard/apikeys → 充值（注册送的额度部分能力用不了，充任意金额解锁）。
- 密钥只放主人自己电脑的环境变量 `BEATAPI_API_KEY`，不写进任何文件、不贴进聊天。公开版执笔不带任何密钥，别人用要自己开。
- **价格**（2026-10-23 从官方查看接口取，按次收费，以官网为准）：

| 要拿的 | 接口 | 单价 |
|---|---|---|
| 抖音评论（一页 20 条） | `data:douyin.app.v3.fetch_video_comments` | $0.003 |
| 抖音按关键词搜 | `data:douyin.search.fetch_video_search_v4` | $0.03 |
| 抖音单条作品数据 | `data:douyin.web.fetch_one_video` | $0.003（免费方法已能拿到） |
| 公众号阅读数、点赞数 | `data:wechat_mp.v2.fetch_article_stats` | $0.03 |

| X 评论 | `data:twitter.web.fetch_post_comments` | $0.003 |

- 查目录、查价格不用密钥：`beatapi.py find "关键词"`；价格要直接调官方查看接口 `POST https://api.beatapi.io/v1/capabilities/inspect`，返回里的 `pricing`（工具自带的 `inspect` 会把价格去掉）。
- 每次花钱前告诉主人抓什么、几次、多少钱，同意了才跑。

## 六、国内能付款的同类接口：TikHub（推荐：国内能用支付宝付款）
- BeatAPI 的抖音、公众号接口名和 TikHub 一一对应（例：`data:douyin.app.v3.fetch_video_comments` ↔ TikHub `/api/v1/douyin/app/v3/fetch_video_comments`），BeatAPI 很可能是转卖 TikHub。
- **付款**：支付宝（单日限额 $250）、PayPal、USDT；最低充值 $5；新用户送约 $0.05（约 50 次请求）。（tikhub.io/zh/pricing、/zh/getting-started，10-23 看）
- **价格**：基础 $0.001～$0.01/次，日用量越大越便宜（1000 次以上九折，最低五折）；抖音关键词搜索 $0.01/次（BeatAPI 是 $0.03）。
- **我们要的接口都有**：抖音单条作品 `/api/v1/douyin/app/v3/fetch_one_video`、评论 `/api/v1/douyin/app/v3/fetch_video_comments`、搜索 `/api/v1/douyin/search/fetch_video_search_v2`，**抖音热榜 29 个接口**（找爆款候选正好用）、星图约 20 个；公众号文章统计（阅读、点赞、在看）`/api/v1/wechat_mp/v2/fetch_article_stats`、评论 `fetch_article_comments`、详情 `fetch_article_detail`、微信搜一搜 `/api/v1/wechat_search/v2/fetch_search`；X 也有。
- 注册 user.tikhub.io/register → 邮件激活 → 控制台拿 API Key → 支付宝充值。密钥放本机环境变量（名字定为 `TIKHUB_API_KEY`），不进聊天、不进仓库。
- 接法：给抓取工具加一个 TikHub 兜底（和 BeatAPI 同一套接口名，换地址和鉴权头），密钥拿到后实测再写死。
- **10-23 实测（开发者自己的密钥，存在本机只有自己能读的文件里）**：
  - 地址 `https://api.tikhub.io`（`api.tikhub.dev` 也通），鉴权头 `Authorization: Bearer $TIKHUB_API_KEY`；查账户 `GET /api/v1/tikhub/user/get_user_info` 不花钱，返回余额和这把密钥能用的接口范围。
  - 抖音评论 `GET /api/v1/douyin/app/v3/fetch_video_comments?aweme_id=…&cursor=0&count=20`：✅ 一页 20 条，每条带点赞数，总评论数和免费抓的一致。
  - 公众号统计 **要用 POST**：`POST /api/v1/wechat_mp/v2/fetch_article_stats`，JSON `{"url": "<文章链接>"}`（用 GET 返回 405）：✅ 拿到 `read_num`（阅读）、`like_count`、`old_like_count`、`share_count`、`comment_count`、`collect_count`。`old_like` 一般是「点赞」、`like` 一般是「在看」，官方没写明，入库照字段原名记。
  - 两次一共约 $0.011（抖音评论约 $0.001，公众号统计约 $0.01）。

## 七、视频号（执笔加，2026-10-24 实测 4 条通过）
- **免费**：无头浏览器（手机标识）打开分享短链，页面自己调 `channels.weixin.qq.com/finder-preview/api/feed/get_feed_info`，拿到作者、发布时间、四项互动数（**fav＝点赞 👍、like＝爱心 ❤**，和字面相反，对着页面核过；forward 转发、comment 评论）、封面、文案、exportId。直接用 curl 请求会被拒（permission verification failed），必须走浏览器。要装 `pip install playwright`，用本机 Chrome。
- **付费（TikHub，$0.01/次）**：`POST /api/v1/wechat_channels/v2/fetch_video_detail`（`export_id` 或 `share_url`）拿视频地址、`decode_key`、账号 username；`fetch_user_videos`（username，翻页 `last_buffer`）拿这个号的作品列表和互动数；`fetch_video_share_url`（object_id）换回分享短链。
- **下载要分段**：一次要整个文件会被限速到约 24KB/秒；2MB 一段顺序要约 400～500KB/秒（http 比 https 快）。
- **解密**：视频前 131072 字节和 ISAAC64(decode_key) 的密钥流异或，工具下完自动解开，解开后开头是 `ftyp`。
- 命令：`scrape.py https://weixin.qq.com/sph/<id> --with-media --transcribe --fallback-tikhub`；只要数据不加 `--fallback-tikhub`，不花钱。
- 找候选：`库/找视频号候选.py`（给号的一条作品链接 → 翻近期作品 → 按 like 取前 2 → 换短链）。
- 实测 4 条（3 个 AI 应用类账号）：免费数据 4/4，视频＋逐字稿通过；逐字稿有同音错字（「Grok Bot」转成「Grogg Bolt」），拆卡时对着标题核。
