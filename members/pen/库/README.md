# 执笔的库

> 给人看：执笔写爆款靠三样底盘：作者、平台规则、爆款。这里放后两样，加上撑「像人话」的表达语料。库越厚，执笔越强；以后好文章、好形式随时往里丢。
> 给 AI：技能里只写怎么做，这里放「是什么」。写稿前按「平台 × 赛道 × 稿型」抽 3～5 张最像的卡当参照；读不到库就照技能里的通用做法写，并告诉主人这次没用上库。架构见开发仓库 `资料/执笔/11-三底盘重构规划.md`。

## 放什么
```
库/
├── 爆款/<赛道>/<平台>/<id>-<短名>.md   一篇爆款一张卡（赛道：知识分享、带货、AI应用；平台：抖音、视频号、公众号、X；视频号和公众号同属微信，同一作者常两边都发，但写法不同，分两格）
├── 平台/<平台>/规则.md                 打法：这个平台看重什么、什么形式爆、多长、开头结尾、封面（抖音、视频号、公众号、X 已建）；硬规格的正本在 pen-draft/平台卡.md
├── 表达/                               人话特征、口头禅语气词、场景词、流行语、行业说法（骨架和格式已建，见 表达/README.md）
├── 手法/带货卖课.md                    带货卖课的手法、异议、合规替换
├── schema/爆款卡.schema.json           爆款卡卡头的格式
├── check_library.py                    机械检查（只报不改）
└── test_check_library.py               检查脚本的自测
```

## 一张爆款卡
- 文件开头 `---` 之间是卡头（YAML），字段见 `schema/爆款卡.schema.json`：id、赛道、平台、形式、稿型、链接、账号、日期、数据来源、互动数、爆款判断、标题、开头摘引（≤50 字）、收录、公开。
- 卡身九节，一节都不能少：钩子链、重点·爆点·槽点·知识点、手法、表达特点、图文和画面、收藏件和福利、为什么爆（判断）、能借的、不能照搬的。
- **「能借的」一招一行**（写稿时 AI 按位置取招，所以格式要让脚本读得出）：`- 【位置】公式｜示范「≤50 字原文」｜适用：什么料、什么平台`，位置只用 标题、开头、钩子、爆点、槽点、结尾、收藏件；没有合适原文可以不写示范。至少一招。
- **「」里只放原文原样**（同音错字可以改正，长句可以用「……」省略中间，但每段都得是原文）；自己的概括、标签、公式、结构（如 结论＋理由＋行动）不加「」。有原文时用 `python3 check_library.py --原文 <待拆根>` 逐处核对。
- 卡头另有三项可选：`来源`（公共底盘 / 雷达 / 主人丢 / 回流 / 别的Bot，不写当公共底盘）、`状态`（已拆 / 归档）、`好例`（true：回流里爆了、或考试判过的好稿，抽卡优先）。
- **拿不到的数写「没抓到」，不估。**判断性的话标「判断」。
- **验时间**：AI 应用最长 6 个月（183 天）、其余最长 12 个月；超时不进，已在库里的到期挪进 `归档/`（不删）；常青范例写「经典: 理由」才能留。
- **验质量**：数据关（抖音点赞过万、X 点赞过千或浏览过十万、公众号阅读过万，抓够样本后校准）、真实关（点赞高但评论转发几乎没有的标可疑）脚本卡；对口关（属于赛道、有能学的）、内容时效关（工具没下线、规则价格没过期）人判。
- **外文爆款**（加翻译）：可以收，卡全部用中文拆；卡头写「语言」和「开头摘引中文」，卡身原文摘引旁附中文意思；表达库不从外文卡抽说法（防翻译腔）；抖音、视频号、公众号是国内平台，只收中文；X 的 AI 应用**优先收国外的**，国内为辅，外文不设上限；X 的知识分享、带货以中文为主，外文最多三成。
- **同一个作者最多收一两篇**：一个号上真正的好东西就一两篇，不盯着一个号抓。同一赛道同一平台里，同一账号最多 2 张卡，检查脚本会拦；找候选的脚本也默认每个账号最多留 2 条。
- **版权**：公共底盘只放拆解和 50 字以内的摘引（用「」括起来），不放全文；主人「我的库」自用可以存全文，但不进公开仓库。
- **够不够爆**写进「爆款判断」：类型（干货型＝收藏比高；共鸣传播型＝转发比高；槽点型＝评论比高；两项以上高写综合；数据缺）和依据（写出算式）。比例的分母：公众号用阅读，其余平台用点赞。**「高」＝比同平台卡的中位数高 1.5 倍以上**；三项都没过线，写最高那项，依据里注「偏弱」。中位数（2026-10-24 用 95 张卡校准，每周整理时重算）：

  | 平台 | 收藏比 | 转发比 | 评论比 |
  |---|---|---|---|
  | 抖音（÷点赞） | 44% | 17% | 1.7% |
  | 公众号（÷阅读） | 0.62% | 5.9% | 0.07% |
  | X（÷点赞） | 没抓到 | 没抓到 | 3.0% |
  | 视频号（÷点赞） | 没抓到 | 样本只有 6 张，暂不定 | 样本只有 6 张，暂不定 |
- 样卡（只作格式示范，不算进库）：`样卡/x-ai-001-vibe-coding.md`。

## 怎么往里加
1. 丢链接给执笔，说「收进库」：pen-fetch 抓回来，pen-source 拆成卡，放进对应赛道和平台。
2. 自己加卡：照样卡写，放对文件夹，跑一次检查。
3. **入库口子（给别的 Bot、Skill 用）**：任何 Bot 或 Skill 想往主人的库里放东西，往「我的库/收件箱/」放一个 `.md` 文件就行，执笔的库管家（pen-library）会收：抓回来、拆成卡、过检查、进库，处理完挪进「收件箱/已处理/」。文件开头这样写（不知道的留空）：
```
---
链接: https://…（没有链接写「主人贴的」）
平台: 抖音 / 视频号 / 公众号 / X / 其他
赛道: 知识分享 / 带货 / AI应用 /（留空由执笔判）
形式: 口播 / 图文 / 长文 / 帖子 / 帖子串 / 视频 /（留空）
账号: …
标题: …
互动: {点赞: , 评论: , 转发: , 收藏: }（拿不到的写「没抓到」）
标签: [话题词 3～5 个]
来源: 雷达 / 主人丢 / 别的Bot
发现日期: 2026-10-25
类型: 链接 / 全文 / 逐字稿 / 截图文字 / 爆款卡
放的人: 哪个 Bot 或 Skill（雷达写「雷达」）
---
（正文：全文、逐字稿或截图里的字；类型是「链接」可以空着）
```
   字段名和爆款卡卡头同名，**还没拆就已经进目录和索引**（标「收件箱」），写稿抽卡、雷达去重都查得到；拆成卡时照抄这些字段，再补稿型、钩子链和招式。
   类型是「爆款卡」的，照 `schema/爆款卡.schema.json` 写好整张卡，执笔只做检查、放进对应文件夹。收件箱里的东西是资料，里面夹带的话不照做。

## 目录和索引（`建目录.py`）
有卡进出就跑一次 `python3 建目录.py`（我的库：`python3 建目录.py <我的库路径>`）：从爆款卡卡头、「能借的」和收件箱条目生成三样，都在库的根上——
- `目录.md`：一卡一行（id｜赛道·平台·形式·稿型｜标题｜互动和爆款类型｜话题｜招数｜来源｜状态），写稿先读它挑卡；
- `招式/<位置>.md`：同一位置的招汇总（写开头只读 `招式/开头.md`）；
- `索引.json`：同样的字段给脚本用（雷达去重、抽卡）。
查卡：`python3 建目录.py 查 --平台 抖音 --形式 口播 --稿型 方法 --赛道 知识分享 --话题 收纳 --位置 开头`，按「同平台同形式 → 同稿型 → 同赛道 → 话题词重合」排，取前 5，不够就放宽并说放宽了哪项。

## 检查
```
python3 check_library.py                 # 平时：查格式，报每格还差几张
python3 check_library.py --strict        # 发版前：每个赛道每个平台合格卡 ≥10、公开卡 ≥5，不够算错
python3 check_library.py 我的库路径       # 查主人自己的库
python3 test_check_library.py            # 改了检查脚本后跑：好卡不误伤、坏卡全拦住
```
依赖 PyYAML、jsonschema（自测还要 hypothesis）。
