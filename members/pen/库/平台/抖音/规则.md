# 抖音 · 打法

> 给人看：抖音上什么样的内容容易爆、为什么。硬规格（字数、导流禁用词）不在这里，在执笔 pen-draft 的 `平台卡.md`「抖音」「抖音长文」两节，那是正本。
> 给 AI：写抖音稿前读这份＋平台卡。每条打法后面写了依据等级：**官方**（平台自己公布）、**报道**（媒体转述官方）、**行业说法**（非官方，当参考不当规矩）、**库归纳**（爆款样本算出来的，写样本数和日期）、**判断**（从前面几条推出来的）。和作者档案冲突时以作者为准。

## 一、平台看重什么
| 打法 | 依据 |
|---|---|
| 推荐系统预估每个观众对这条内容的**完播、评论、点赞、长期关注作者、分享、跟拍**等多个行为的概率，加总价值高的推给他；北极星是「用户长期价值」 | 报道：抖音安全与信任中心公开算法原理（新华网 2025-04-16） |
| 观众点「不感兴趣」会压低推荐 | 报道：同上 |
| 质量高的内容被选进「抖音精选」有机会拿流量扶持 | 报道：同上 |
| 新作品先进小流量池（几百人），完播、点赞、评论、收藏达标再推更大的池 | 行业说法（人人都是产品经理等，2020 年起多次转述，非官方原文） |
| 完播率 15%～20% 算及格，40% 以上算好 | 行业说法 |
| **所以**：开头 3 秒留住人（完播）、中段每 10～15 秒一个新钩子、结尾给一个能接话的槽点（评论）、给一样值得存的东西（收藏和分享） | 判断 |

## 二、什么形式爆、多长
| 打法 | 依据 |
|---|---|
| 口播短视频为主；长图文（8000 字、30 张图）2025 年底上线，推荐流里以视频形式展示 | 平台卡（报道，多方一致） |
| 爆款口播并不短：知识分享时长中位 **180 秒**，带货 **275 秒**，AI 应用 **382 秒**。「60～90 秒」是起步默认，干货讲透可以写到 3～6 分钟，前提是每段都有新东西 | 库归纳（入选 91 条，2026-10-23 采集） |
| 爆款大多是**干货型**（收藏多）：收藏÷点赞中位知识分享 0.44、带货 0.29、AI 应用 0.69；评论÷点赞都只有 0.014～0.018 | 库归纳（同上） |
| AI 应用类收藏率最高（0.69）：教程、工具清单、一步步的操作最被存 | 库归纳（入选 20 条） |
| 带货类「综合型」最多（16/35）：既要有干货让人存，也要有情绪让人转 | 库归纳（入选 35 条） |

## 三、开头、节奏、结尾
| 打法 | 依据 |
|---|---|
| 前 3 秒就给钩子：结果、反差、问题、利益，不寒暄、不自我介绍 | 形式卡；和「完播」目标一致（判断） |
| 一句不超过 25 字，念得顺；每分钟 220～260 字 | 形式卡 |
| 结尾用槽点引评论（真问题、真争议），不编争议 | 钩子卡；评论是推荐预估目标之一（报道） |

## 四、封面和画面
| 打法 | 依据 |
|---|---|
| 竖版 9:16；封面大字、两行以内，封面数字和口播一字不差 | 平台卡＋pen-cover |
| 口播配画面：数字对比、步骤、清单做成字幕卡或图，口播只留一句 | pen-cover（判断） |
