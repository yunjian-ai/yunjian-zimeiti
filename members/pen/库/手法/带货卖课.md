# 带货卖课：手法、异议、合规替换（库）

> 给人看：卖东西的稿子能用的手法、观众的担心怎么答、有风险的说法换成什么。每个手法都要主人给真材料，没有就不用，不编。
> 给 AI：做法在执笔 `带货卖课卡.md`（结构、觉知、挑刺审稿）；这里是查表用的知识，读不到这份就照 `规则卡.md` 第 1、8 条写。来源：`资料/执笔/10-带货卖课对标.md`。

## 一、手法（每个都要主人给的料）
| 手法 | 做法 | 要主人给 | 别用的时候 |
|---|---|---|---|
| 感官占领 | 替观众「试用」一遍：看到、听到、摸到、尝到、心里的感觉 | 主人自己用的真体验 | 主人没亲自用过 |
| 恐惧诉求 | 一个具体的痛苦场景＋不解决的后果 | 观众真遇到过的痛点 | 享乐型产品；居高临下、给观众贴标签 |
| 认知对比 | 旧办法差在哪、对观众少了什么 → 这个好在哪、多了什么，一一对应 | 真实的差别 | 点名诋毁同行；全新品类没得比 |
| 使用场景 | 替观众想好什么时候用，具体到时间地点 | 主人或顾客的真实用法 | 用「随时随地」糊弄 |
| 顾客证言 | 只挑说中核心需求的一两条，保留原话口气；有真销量可以说 | 真评价、真销量 | 没有真评价；医疗效果 |
| 权威转嫁 | 这个权威多有分量＋拿到有多难，两句都要 | 真奖项、真认证、真合作 | 没有就不写，不傍名人 |
| 事实证明 | 精确数字 → 换成观众熟悉的东西；或一个看得见的对比实验 | 实测数据、主人做过的实验 | 没测过 |
| 价格锚点 | 先给真实可查的参照价，再报实际价 | 真实对比价和口径 | 虚构原价、划线价 |
| 算账 | 总价 ÷ 用多久，或每次省多少 × 用几次，一步算完 | 真实价格和合理用期 | 低价冲动品；夸大用期 |
| 正当理由 | 把买它说成上进、送礼、健康、孩子 | 和产品真有关系 | 硬凑 |
| 限时限量 | 真实的截止点、真实名额 | 真的有 | 说不出截止就不写 |
卖课再查一遍**价值**：观众想要的结果 × 相信能做到（证据、交付方式）÷（要等多久 × 要付出多少）。哪项弱，就请主人补那一项的真材料（学员原话、第一周能做出什么、每天要花多久），不靠夸大补。

## 二、异议（主动替观众问，再答）
| 担心 | 怎么答 |
|---|---|
| 嫌贵 | 先把价值讲足再报价；和同价位比，不和低价货比；说出「怕花得不值」再回应 |
| 怕假、怕被骗 | 不说「绝对正品」；给细节、资质、可退可验 |
| 怕不适合、怕学不会 | 说清适合谁、不适合谁；有试用、试听就说 |
| 怕没效果 | 先降预期，讲正确用法和合理周期 |
| 怕售后 | 讲清退换规则和流程 |

## 三、合规替换（说法有风险就换）
| 不能说 | 换成 |
|---|---|
| 最后两单、最后 3 分钟（不真实） | 真实库存才报数；或说「本场的赠品只在本场」 |
| 全网最低价、亏本清仓、跳楼价、原价 1999 今天 199（虚构） | 「这是这场的价格」「比日常便宜 N 元」（真实差额，说明口径） |
| 绝对正品、质量保证没问题 | 细节展示＋资质产地＋可退可验 |
| 第一、顶级、最好、买到顶、毕业款 | 具体好处或数字 |
| 治疗、减肥、改善疾病（普通商品） | 主人自己的真实感受 |
| 一周变现、保证通过、百分百有效、月入过万（卖课） | 课里教什么、怎么交付、主人或学员的真实结果加条件 |
| 扣 1 领福袋、转发朋友圈领奖 | 用互动确认意向，不和利益绑定 |
| 口播微信号、二维码、「私下找我」 | 只走平台允许的方式（照 `平台卡.md`） |
口播里的卖点、参数、赠品，要和商品页一致。
