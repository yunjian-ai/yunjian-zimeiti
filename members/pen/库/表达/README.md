# 表达库

> 给人看：撑住「像人话」的语料——真人怎么说话、各行的人怎么说、现在流行什么说法。执笔改稿时照人话卡一层层换，这里是第二、三层的料。越攒越像人。
> 给 AI：pen-polish、pen-draft 照 `人话卡.md` 第二节用；pen-library 每周从新入库的爆款卡里抽候选。**不收 AI 写的东西，不从外文卡抽**（防翻译腔）。读不到就跳过这一层。

## 放什么
```
表达/
├── 人话特征.md          八个维度（人话卡第一节）各配真人原句
├── 口头禅和语气词.md
├── 场景词.md            具体物件、时间地点、动作，按场景分
├── 流行语.md            会过期，每条带年份和平台
└── 行业/<行业>.md       知识付费、带货电商、餐饮、美业、教育培训、生活服务先做
```

## 一条怎么写
```
- 说法：「……」
  例句：「……」（原句，≤50 字）
  出处：爆款卡 id / 公开真人语料链接 / 主人样稿（我的库才放）
  平台：抖音 / 视频号 / 公众号 / X｜人群：……
  首次见到：YYYY-MM｜最近见到：YYYY-MM｜出现次数：N
```
- 流行语、行业新词必须写「首次见到」「最近见到」；最近见到超过 6 个月标「过气」，写稿时不用。
- 行业说法分三类写：行话（同行之间说的）、观众的说法（客户怎么描述他的问题）、常见比喻。
- 每条都要有出处；拿不准是不是真人说的，不收。
