## 钩子链
1. 从异常和禁言场景切入：「如果你的 DeepSeek 出现这种情况，或者直接被禁言」，随即把 API 接入说成解决方案。
2. 立即进入官网、余额、创建并复制密钥等连续操作，用短路径留住有燃眉之急的人。
3. 再按手机系统给客户端选择，演示启用服务、粘贴密钥和获取模型。
4. 结尾用 Token 费用提醒收口，避免观众只接成功却忽略成本。

## 重点·爆点·槽点·知识点
- 重点：从 DeepSeek 官方 API 获取密钥，再到客户端启用服务、选择模型。
- 爆点：77 秒内给出从异常到配置成功的完整路径，直击被限制后的即时需求（判断）。
- 槽点：评论反复追问收费、自动扣费、客户端和接入后仍无法生成；有人问「为什么接上了也在拒绝生成呀[流泪]」，说明接入不等于所有限制消失（判断）。
- 知识点：API 使用与余额、Token 消耗有关；输入越多成本越高，模型选择影响费用。

## 手法
- 用具体故障替代泛泛的工具介绍，精准筛选有需求的人。
- 全程按点击顺序讲，几乎不展开原理，压缩复现成本。
- 把不同系统的客户端选择集中交代，减少评论追问。
- 最后补成本风险，给前面的完美解决增加约束。
