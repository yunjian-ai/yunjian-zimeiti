# 锁定清单卡

> 卡类：口径｜改了要回归考题

## 一、三份清单的样子
每项一行「- 名称：内容」，名称照下面原样写（`check_reel.py` 按名称查），看不到的写「推测：……」。必填：人物——发型、脸、上装、下装、鞋、必须出现、禁止；货品——品名、颜色、图案、版型、必须出现、禁止；场景——场景、灯光、背景、地面、禁止。

**人物清单-v1.md**
```
# 人物清单 v1（2026-10-27）
- 称呼：阿杰
- 发型：寸头、黑色，两侧推短
- 脸：方脸、双眼皮、浓眉、下巴有胡茬
- 痣／记号：左眉尾一道浅疤（没有写「无」）
- 上装：（穿货就写「穿货品清单那件」）
- 下装：黑色工装裤，长到鞋面、裤脚堆一点（下装一定写长度）
- 鞋：棕色高帮皮靴
- 配饰：左手腕银色手链，每一刀都有（没有写「无」）
- 必须出现：眉尾的疤；手链
- 禁止：叉腿、深蹲；留长发；加耳钉；衣服上加字
- 推测：后脑推短的高度（照片看不到背面）
```
**货品清单-v1.md**
```
- 品名：燕麦色粗针织开衫
- 颜色：燕麦色（偏暖的米灰），全身一个颜色
- 图案：前片两条竖向麻花纹，原样，不变成格子或条纹
- 版型：正肩、短款、长到腰
- 细节：V 领；5 颗深棕木扣；袖口罗纹
- 必须出现：麻花纹；5 颗木扣
- 禁止：任何字和 logo；扣子数不对；加帽子
```
**场景清单-v1.md**
```
- 场景：老城区街角，红砖墙前的人行道，傍晚
- 灯光：夕阳从画面右后方低角度打来（逆光），左边有一盏暖黄路灯刚亮
- 背景：红砖墙，墙上一扇绿色铁门在画面右三分之一
- 地面：灰色方砖人行道，有一道浅浅的积水反光
- 道具：铁门旁一辆旧自行车（视角 2 看得到对街的便利店招牌，招牌只要色块、不要字）
- 禁止：别的行人；车牌和招牌上的字；涂鸦
```

## 二、定妆图提示词骨架（中文写，参考图顺序写清）
- **人物三视图**：参考图 1＝人物照片，有货再加参考图 2＝货品照片。「同一个人的正面、侧面、背面三视图，全身站直、双脚与肩同宽、双手自然下垂，纯白背景、平光，＋人物清单全文（有货就穿着货，后面每一刀都照这一身），不加任何字」。
- **标准脸**：参考图 1＝人物照片。「正脸特写、平视镜头、平光、纯白背景、表情自然、嘴闭着，＋发型、脸、痣」。
- **货品多视图**：参考图 1＝货品照片。「同一件商品的正面、背面、侧面、45 度和细节特写，纯白背景平铺或隐形人台，＋货品清单全文」。
- **场景视角 1**：参考图 1＝场景照片。「空场景、主视角、不放人，＋场景清单全文，9:16 竖构图（或按画幅）」。
- **场景视角 2**：参考图 1＝场景视角 1。「同一个空间的反打视角（从对面看回来），补出视角 1 看不到的那一侧，灯的位置、颜色、地面和视角 1 一致」。
- **试镜 4 张**：参考图依次＝标准脸、人物三视图、货品多视图、场景视角 1。「景别（特写／半身／全身／远景）＋人物在场景里的动作（站直、重心在一条腿）＋人物清单＋货品清单＋场景清单＋风格（风格预设那一行）＋禁止项」。

## 三、核对顺序（每张出完逐项看，哪项不对写进重出提示词的最前面）
1. 脸像不像标准脸（五官、痣）　2. 发型、发色　3. 上装：颜色、图案原样、版型　4. 下装长度　5. 鞋　6. 配饰有没有多、有没有少
7. 货上有没有多出字和 logo　8. 场景：灯的方向、背景色、该有的陈设　9. 姿势像不像真人（叉腿、深蹲、手指数）　10. 画面里有没有乱出的字
- 最多重出 4 次；还不对就换景别避开那一处（比如手总出错就换不露手的景别），不拿修图把毛病抹掉了事。
