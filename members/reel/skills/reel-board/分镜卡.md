# 分镜卡

## 一、镜头表每一列怎么填
| 列 | 填什么 | 例 |
|---|---|---|
| # | 刀号，从 1 起 | 3 |
| 进–出（秒） | 切点.py 给的，不手改（要改就改参数重出） | 3.437–5.155 |
| 景别 | 远景／全身／中景／近景／特写／大特写，相邻两刀不同 | 近景 |
| 场景／机位 | 场景视角 1 还是 2，高机位、低机位、平视 | 视角 2，低机位 |
| 镜头动作 | 只写一个，词从 `库/分镜模板.md` 挑 | 慢推 |
| 人物动作 | 小、像真人，一句话 | 抬手把袖口往上拉 |
| 表情／酷动作 | 这刀的关键帧：眼神、手、表情 | 拉完袖口抬眼看镜头，嘴角一挑 |
| 主体位置 | 9:16 一般居中；避开上 10%、下 20%、左右各 6%（字和按钮会挡） | 居中偏下 |
| 大字 | 一刀一个词，2～4 个字或一个英文词 | GO |
| 素材 | `视频/03.mp4`；开场纯大字写「—」 | 视频/03.mp4 |
| 备注 | ⚡大落点、片尾卡、要退回静帧的写这 | ⚡大落点：放最猛的镜头 |

## 二、关键帧三条（每条片子都照做）
1. **运镜要炫**：大落点那刀给最有冲击的镜头动作（快推到特写、低机位仰拍跟着走、甩镜）；平时的刀慢推、横移就够。
2. **手部细节**：至少一刀给手的特写（拉袖口、拨头发、摸货的质感、弹琴的手）。
3. **表情和酷动作**：每刀写清这一下脸上是什么（抬眼、回头、嘴角一挑、低头笑）；这是关键帧，出静帧时就照它出。

## 三、一条 15 秒片子的节奏（9 刀左右）
- 第 1 刀：钩子。最抓人的画面或开场大字，2 秒内让人停下。
- 第 2 刀（常是大落点）：全片最猛的镜头。
- 中段：远、近、特写交替，讲一个小变化（走进来 → 停下 → 看镜头）。
- 手部特写放在中段一刀。
- 最后一刀：全身或远景，留给片尾卡（片名或一句话）。

## 四、好分镜和坏分镜
- 好：「近景｜视角 2 低机位｜慢推｜整理袖口｜抬眼看镜头｜居中｜GO」——一个动作、一个表情、景别和上一刀不同。
- 坏：「近景｜先推近、再横移、最后升起｜边走边唱｜LET GO（显示到下一刀）」——三个镜头动作、对口型、两个词还跨刀。
