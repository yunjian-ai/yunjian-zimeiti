# 钩子卡（带货片前 3 秒）

> 卡类：口径｜改了要回归考题

> 前 3 秒决定人划不划走。同一件货一次写 6～10 个开头，**每个用不同类型**，好让主人挑、也好做 A/B。例子都用一件米白手工开衫（卖点：手工粗针、新西兰羊毛、胡桃木扣），数字只在真测过、吊牌写着时才能用。

## 一、写法
1. 先找「人什么时候会烦」：从用的人的难处出发，不从「货有多好」出发。
2. 台词 ≤18 个字（中文一秒四五个字，3 秒说完）；花字 ≤10 字，是台词的「标题版」，不照抄台词。
3. 第一帧就是货或痛点画面，**不放 logo 片头**；品牌名放到第 2 刀。
4. 不像广告：前几个字像随口说话（第一人称、提问）；不用「最、第一、顶级」。
5. 交付：表格（类型｜台词｜第一帧｜花字｜风险）＋推荐 3 个、各一句理由。

## 二、类型（基础 9 种）
| 类型 | 怎么写 | 开衫的例子 |
|---|---|---|
| 痛点提问 | 你是不是也……？ | 毛衣总扎脖子？ |
| 反差 | 看着像 A，其实 B | 看着厚，其实穿上不闷 |
| 结果先行 | 先给结果的画面，再说 | （先拍扣子特写）这五颗是木头的 |
| 数字 | N 个、N 步（要真的） | 挑开衫先看这两处 |
| 场景代入 | 当你在……的时候 | 早上出门降温的时候 |
| 错误示范 | 别再…… | 别再买一洗就变形的开衫了（主人测过才用） |
| 对比 | 左边普通款，右边这件 | 普通机织 vs 手工粗针，凑近看针目 |
| 第一人称 | 我…… | 我自己穿了一个冬天的开衫 |
| 悬念 | 最后一点最关键 | 选开衫看三处，第三处最多人忽略 |

## 三、更容易让人看完的 7 个角度
| 角度 | 开衫的例子 | 注意 |
|---|---|---|
| 打断划走 | 先别划，你身上这件扎不扎？ | 前五个字不像广告 |
| 跟拍一段时间 | 穿着它过一天，晚上再看起没起球 | 真能拍到时间跨度才用 |
| 对比锚点 | 同一个光下，两件开衫凑近看 | 对比用「普通款」，不点别人家的名 |
| 坦白 | 说实话，我以前觉得开衫都差不多 | 后半句马上接能看见的卖点 |
| 借话题 | 最近都在问开衫怎么选，我只看一点 | 只借话题，不搬别人的画面和音乐 |
| 叫停 | 还在穿扎脖子的毛衣？停一下 | — |
| 没人说的点 | 很少有人说：开衫好不好看，看扣子 | 说的点要真 |

## 四、自查
- [ ] 3 秒说得完（≤18 字）；花字 ≤10 字、不照抄台词
- [ ] 第一帧是货或痛点，不是 logo
- [ ] 数字、效果都有出处（`<项目>/卖点.md`）；没有「最、第一、顶级」
- [ ] 对比只用「普通款」
- [ ] 至少 3 种不同类型，推荐 3 个、写了理由
