# 带货卡（卖点分镜、开箱对比、爆款复刻）

> 卡类：事实｜核对 2026-10-27｜下次核对 2027-01-25（照官方重核一遍，改了日期跟着改）

## 一、结构公式
| 时长 | 结构（刀数） |
|---|---|
| 15 秒 | 钩子(1) → 亮相(1) → 卖点 2～3（每个一刀证明画面）→ 行动号召(1)，共 5～6 刀 |
| 30 秒 | 钩子 → 痛点放大 → 亮相 → 卖点 ×3（每个「说＋证明」）→ 上身或使用场景 → 行动号召，8～10 刀 |
| 60 秒 | 钩子 → 我的经历 → 开箱 → 卖点 3～4 个演示 → 对比 → 缺点和适合谁 → 行动号召，14～18 刀（测评讲解） |
- **一刀一个信息**；最强的卖点放第 2～3 刀。
- **光说不演不算卖点**：每个卖点配一刀看得见的证明。卖点像念说明书时，改成「场景＋结果」（「降温那天披上，到办公室才脱」）。
- 商品 3 秒内出镜、有一段时间在画面中间、整件出现过（抖店主图视频要求，挂详情页的版本必须守）。
- 最后一刀行动号召至少 3 秒（「喜欢就点下方小黄车」）；价格只写主人给的，只放一处（字幕或结尾卡，不两处都放）。

## 二、证明画面词表（服装为例，别的货照这个思路换）
| 卖点类型 | 证明画面 | 镜头动作 |
|---|---|---|
| 做工、针法 | 微距：针目、走线、包边 | 微距推近 |
| 材质 | 手指搓、轻拉回弹、贴脸 | 慢推（手的动作小） |
| 配件（扣、拉链） | 扣子特写、解开扣上一颗 | 慢推、静止 |
| 版型 | 上身正面、侧身、走两步 | 跟、左移 |
| 颜色 | 几个颜色并排挂、模特换色 | 横移 |
| 搭配 | 上身配一条裤子或裙子 | 拉远 |
| 对比 | 左普通款、右这件，同一个光 | 静止 |
女装官方建议展示：模特、细节、搭配、静拍、设计、颜色（抖店主图视频指南）。

## 三、爆款复刻（主人丢来一条同行爆款）
只学**结构和节奏**，不搬画面、配乐、原台词。
1. 拆 8 维：钩子类型｜前 3 秒画面｜5 段节拍（钩子 0–3 → 痛点 3–5 → 亮相 5–8 → 证明 8–13 → 行动 13–15）｜情绪（吐槽、安利、冷静测评）｜花字节奏｜证明方式｜行动号召形式｜能复用和不能复用。
2. **不能复用**的标红：绝对化用语（全网最低、第一）、没出处的数字（100% 纯羊毛）、别人家的梗、联系方式（微信号）、原画面原配乐原台词。
3. 给 3 个复刻角度：**原样同构**（节拍、钩子类型、证明方式都对齐，只换货和卖点）／**换钩子**（同品类已经有人照抄过时）／**换证明**（主人有实拍、或数字测不全时，把念数字换成演示）。每个一句差别、一句推荐理由，主人挑一个再出分镜。

## 四、开箱、对比测评（30、60 秒）
- 开箱：拆包 → 第一眼 → 细节 → 上身 → 适合谁。
- 对比：同一个光、同一个角度、同一个动作；对手写「普通款」，不点名别家；只比主人真测过的项；结论里也说一句缺点或不适合谁（更可信）。
