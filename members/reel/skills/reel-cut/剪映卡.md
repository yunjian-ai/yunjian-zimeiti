# 剪映卡（跑不了命令时，把镜头表翻成主人在剪映里的操作）

交给主人前，把下面的 <> 换成这条片子的真实数字，一刀一行列清楚。

1. 打开剪映 → 开始创作 → 导入：`音乐/歌.wav` 和 `视频/` 里所有素材（没有视频的刀导入 `静帧/<号>.png`）。
2. 画面比例选 9:16（右下角「比例」）。
3. 先把歌拖到音频轨，从 0 秒开始。
4. 按镜头表一刀一刀往主轨上放（每行照填）：
   - 第 <1> 刀：<视频/01.mp4>，选中后用「分割」只留 <0.5>～<2.2> 秒（可用窗口），放在时间线 <0.000>～<1.718> 秒。
   - ……
   静帧那刀：拖进去后把时长改成这刀的长度，加「动画 → 组合 → 缓慢放大」。
5. 每刀在切点那里对一下：时间线放大，切点要落在歌的鼓点上（波形的尖峰）。
6. 大字：文本 → 新建文本，一刀一个词，时长和这一刀一样长；字体选粗体，字号占画面宽度七八成；放在画面中间。
7. 调色：滤镜里挑和风格接近的一个，或者「调节 → LUT」导入 `出片/色彩/<色名>.cube`（掠影用 `调色.py 导出` 给出）。
8. 片尾：最后 2 秒加一层黑色半透明蒙版＋片名文字。
9. 导出：分辨率 1080P、帧率 30、码率「推荐」，格式 MP4。
10. 导出的成片发回给掠影，交 reel-check 质检。
