# 卡点剪辑

## 0. 先读
- `python3 ../reel-brief/check_reel.py <项目>` 要过（可用窗口表不许还有「待看」）；没过回 reel-motion。
- 脚本都在本目录：`成片.py`（主力）、`调色.py`、`抠像.py`、`放大.py`、`字体.py`。要 ffmpeg（没有先问主人，同意后 `pip install imageio-ffmpeg`）。
- 同目录 `改版卡.md`（勾选项、剪辑.json 怎么改）、`剪映卡.md`（跑不了命令时给主人的剪映步骤）。

## 1. 剪辑设置（`<项目>/剪辑.json`，不写就全用默认）
照需求定几项：`调色`＝风格预设对应的那套色（`python3 调色.py 列` 看 6 套；拿不准就 `python3 调色.py 对比 静帧/02.png 出片/调色对比.jpg` 让主人挑）、`HUD.标题`＝片名、`片尾.字`＝片名或主人想让人记住的那句、`片尾.副`、`跑马灯`（不要就留空）。其余开关和默认值见 `改版卡.md` 第二节。
- 第一次用会自动下开源粗体字（中文约 9MB）；网慢超过 3 分钟就先用系统字体。主人有自己的字体：放进 `<项目>/字体/`，优先用它。

## 2. 粗剪（关口：主人没点头不出成片）
`python3 成片.py 粗剪 <项目>` → `出片/粗剪/粗剪.mp4`（半尺寸、快）＋ `出片/粗剪/联系表.jpg`（每刀中间一帧，标刀号、时间、大字）。
- 它会先跑镜头表体检、核对每刀不超过可用窗口；不过会停下说哪刀哪里不对——回 reel-board 或 reel-motion 改，**不加 `--跳过体检`、`--允许超窗` 硬出**（主人明说才加）。
- 发给主人：粗剪视频＋联系表，问「顺序、节奏、大字对吗？」。主人点头：`python3 ../reel-brief/进度.py 记 <项目> "原话"`，`关口 <项目> 粗剪 过`。

## 3. 字压在人身后（能抠像就做）
- Grok Bot：在它自己的云端电脑上装抠像（`pip install "rembg[cpu]"`，不占主人电脑），然后 `python3 成片.py 底片 <项目>` → `python3 抠像.py 出片/底片.mp4 出片/遮罩.mp4`。
- 主人自己的电脑：先问「要不要装抠像（约 170MB）让大字压在人身后？不装大字就放在人前面」，主人同意才装。
- 有 `出片/遮罩.mp4`，成片会自动把大字压在人身后；近景、特写、大特写那几刀人占满画面，字压在后面会被整个挡住，成片自动把这几刀的字放到人前面（Grok Bot 实测发现）。

## 4. 出成片
- 先看几帧：`python3 成片.py 几帧 <项目> --秒 1.8,5.2,14.0`（字、调色、片尾各挑一帧），自己看一眼字有没有挡脸、出没出安全区。
- `python3 成片.py 成片 <项目>` → `出片/成片.mp4`（1080×1920、30 帧、码率不超 8.5Mbps、响度 -14 LUFS）；同名 `.设置.json` 记下这版用的设置。超过 2 分钟的用 `python3 ../reel-brief/进度.py 后台 <项目> 成片 -- python3 成片.py 成片 <项目>` 放后台，告诉主人好了说「继续」。
- 要 4K（发抖音）：`python3 放大.py 出片/成片.mp4 出片/成片_4K.mp4`；视频号用 1080 那版（码率上限 10Mbps）。
- 交 reel-check 质检。

## 5. 改版（主人说「字太大」「节奏慢了」）
照 `改版卡.md` 第一节发勾选项，**只改勾到的**。主人已经说清改哪几项（「字太大，节奏慢了点」）：先把这几句对上勾选项编号说给主人（「对应第 1 项字小一点、第 3 项切快一点」），再附整张勾选表问「还有别的要改吗？」，主人回了再动手。
- 字、调色、闪帧、片尾这类：改 `剪辑.json` 那一项，重出成片——会自动出 `成片_v2.mp4`，**旧版不删**。
- 节奏：回 reel-board 改切点（一刀一小节 → 半小节），换掉的刀回 reel-motion 只出那几刀。
- 换某几刀：回 reel-motion 只重出那几刀，其余不动。
- 改了切点或换了刀：先 `关口 <项目> 粗剪 撤`，重出粗剪请主人再点头，再出成片；只改剪辑.json 的（字、调色、闪帧、片尾这类）不用重新过粗剪。
- 每改一版，主人的话 `进度.py 记` 原样记下。

## 6. 跑不了命令（没有 shell）
照 `剪映卡.md` 把镜头表翻成剪映的一步步操作交给主人，素材和窗口时间一起给。

## 不做
发布（主人自己点）；拿没过质检的成片当交付（交 reel-check）；换歌、改分镜不问主人。演练模式下只打印要跑的命令和剪辑设置，不出片。
