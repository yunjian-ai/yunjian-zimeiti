# 分镜模板：景别和镜头动作词表

## 一、景别（相邻两刀不同）
| 景别 | 画面里有什么 | 常用来 |
|---|---|---|
| 远景 | 人占画面高度三分之一以内，整个场景都在 | 开场交代在哪、片尾 |
| 全身 | 头到脚都在 | 看整套穿搭、走路 |
| 中景 | 膝盖以上 | 动作、和货互动 |
| 近景 | 胸口以上 | 表情、上装细节 |
| 特写 | 脸或手占满 | 眼神、手部细节 |
| 大特写 | 眼睛、扣子、面料纹理 | 卖点细节、大落点前的一下 |

## 二、镜头动作（一刀只挑一个）
| 中文 | 英文（给视频模型时可以中英都写） | 效果 | 稳不稳 |
|---|---|---|---|
| 慢推 | slow push in / dolly in | 越来越近，聚焦 | 很稳 |
| 快推 | fast push in / crash zoom | 冲击，适合大落点 | 稳 |
| 慢拉 | slow pull out / dolly out | 越来越远，收尾 | 很稳 |
| 横移 | truck left / truck right | 平着滑过，带出场景 | 稳 |
| 跟拍 | tracking shot, follow from behind / side | 跟着人走 | 人走要真迈步才稳 |
| 升 | crane up / pedestal up | 往上抬，开阔 | 稳 |
| 降 | crane down | 往下落，落到人身上 | 稳 |
| 摇 | pan left / pan right | 机位不动、转头看 | 稳 |
| 俯仰 | tilt up / tilt down | 从脚看到脸、从脸看到脚 | 稳 |
| 弧移 | arc shot（半圈以内） | 绕着人转一点，立体 | 半圈以内稳，**不转整圈** |
| 低机位仰拍 | low angle | 人显高、显酷 | 很稳 |
| 甩镜 | whip pan | 两刀之间的转场 | 一般，少用 |
| 手持 | handheld, slight shake | 真实感 | 稳（但不算镜头动作，可以叠在上面任何一个） |
**不用**：360 度环绕（转一圈脸和衣服会走样）、一刀里「先……再……」接两个动作。
